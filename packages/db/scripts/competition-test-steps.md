# ขั้นตอนทดสอบระบบแข่งขัน (local)

ใช้กับ `bun run dev` (เว็บ `http://localhost:3001`, API `http://localhost:3000`) บน branch ที่รวมสาย B ครบแล้ว

## 0. เตรียม

1. เปิด `bun run dev` ไว้ 1 ตัว (ห้ามเปิดซ้อน)
   ต้องมีงานสาย B ครบแล้ว (โดยเฉพาะ engine คะแนนจาก B3) สคริปต์ใช้ engine คำนวณผลของแมตช์ที่จบแล้ว
2. ใส่ข้อมูล mock:

   ```bash
   bun packages/db/scripts/seed-competition.ts
   ```

   - รันซ้ำได้ทุกเมื่อ: ลบข้อมูล mock และ **ทุกแถวในตาราง `competition_*`** แล้วใส่ใหม่ เวลาแมตช์คิดจากตอนรัน
   - ลบทิ้งทั้งหมด: `bun packages/db/scripts/seed-competition.ts --clear`
   - บัญชีจริงในเครื่องไม่ถูกแตะ ถ้าที่นั่งหัวหน้า/รองกีฬายังไม่ผูกบัญชี บัญชี mock จะนั่งแทนชั่วคราว และคืนเป็นว่างเมื่อ `--clear`

3. **เข้าใช้เป็นบัญชีทดสอบ (persona):** เปิดหน้าต่างไม่ระบุตัวตน (Incognito) ไปที่ `http://localhost:3001` เปิด DevTools → Console แล้ววาง

   ```js
   document.cookie = "better-auth.session_token=<cookie>; path=/";
   location.href = "/staff/dashboard";
   ```

   เอา `<cookie>` จาก `packages/infra/.alchemy/local/mock-sessions.json` (อยู่ใน `.alchemy` จึงไม่ถูก commit) เปลี่ยน persona: ลบ cookie แล้ววางใหม่ หรือเปิด Incognito ใหม่
   ทางเลือก: บัญชี admin ของคุณใช้ “ดูในมุมมองของ…” ได้ แต่โหมดนั้นอ่านอย่างเดียว ใช้ลองว่าเห็นเมนูอะไร ไม่ใช่ลองบันทึก
