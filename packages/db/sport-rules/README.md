# กติกา IT3K ครั้งที่ 21 (Markdown)

แปลงจาก PDF ประกาศกฎและรูปแบบการแข่งขัน (ตัวเลขไทยเปลี่ยนเป็นเลขอารบิก)

- `regulation.md` คือระเบียบว่าด้วยการจัดการแข่งขัน ใช้กับทุกกีฬา ระบบยังไม่ได้ใส่ไว้ในฐานข้อมูล
- ไฟล์อื่นตั้งชื่อตามรหัสกีฬา (`football.md`) หรือรหัสประเภท (`esports-rov.md`, `folk-relay.md`)

migration `seed_sport_rules` ใส่ไฟล์เหล่านี้เป็นกติกาเริ่มต้น โดยเว้นกีฬาหรือประเภทที่มีกติกาอยู่แล้ว
หลังจากนั้นให้แก้กติกาที่หน้า `/staff/sports` → กติกา ซึ่งอัปโหลดไฟล์ `.md` แทนได้ด้วย
การแก้ไฟล์ในโฟลเดอร์นี้ไม่เปลี่ยนกติกาที่อยู่ในฐานข้อมูลแล้ว และห้ามแก้ migration ที่รันไปแล้ว
