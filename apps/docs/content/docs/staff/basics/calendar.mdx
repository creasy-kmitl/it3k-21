## เลือกมุมมองและแผนก

- **มุมมอง:** เดือน · สัปดาห์ · วัน · รายการ ใช้ปุ่มลูกศรเพื่อเลื่อนช่วงเวลา
- **แผนกที่แสดง:** แผนกของฉัน (ค่าเริ่มต้น) ทุกแผนก หรือเลือกหลายแผนกเอง
- **ค้นหา** และกรองตาม **สถานะ**

| สถานะ        | ความหมาย                                          |
| ------------ | ------------------------------------------------- |
| ร่าง         | ยังไม่ยืนยัน อาจเปลี่ยนวันเวลา                     |
| ยืนยันแล้ว   | กำหนดแน่นอนแล้ว                                    |
| ยกเลิก       | ยกเลิกแล้ว ยังเก็บไว้ในปฏิทินเพื่อให้ทุกคนรู้       |

## เพิ่มรายการ

<Steps>
<Step>

### กด “เพิ่มรายการ”

หรือกดช่องว่างในปฏิทินตรงวันและเวลาที่ต้องการ ระบบจะใส่เวลาเริ่มให้

</Step>
<Step>

### กรอกรายละเอียด

**ชื่อรายการ** **แผนก** **สถานะ** เวลา **เริ่ม** และ **สิ้นสุด** และถ้ามี **สถานที่** **ผู้รับผิดชอบ**
**ฝ่ายที่ทำงานร่วมกัน** และ **โน้ตภายใน**

</Step>
<Step>

### บันทึก

รายการจะขึ้นในปฏิทินของแผนกคุณ และของฝ่ายที่ทำงานร่วมกัน ผู้เกี่ยวข้องจะได้รับการแจ้งเตือนที่กระดิ่ง

</Step>
</Steps>

## แก้ไข เลื่อน หรือยกเลิก

กดรายการเพื่อเปิดรายละเอียด แล้วกด **แก้ไขรายการ** ถ้าเลื่อนเวลาหรือเปลี่ยนเป็น “ยกเลิก” ระบบจะถาม
**เหตุผลที่เลื่อนหรือยกเลิก** ซึ่งบันทึกไว้ใน **ประวัติการเปลี่ยนแปลง** ให้ทุกคนย้อนดูได้

## ใครทำอะไรได้

| การกระทำ                              | ใครทำได้                                                  |
| ------------------------------------- | --------------------------------------------------------- |
| ดูรายการทุกแผนก                       | ทีมงานทุกคน                                                |
| เพิ่มรายการ                           | ทีมงานที่สังกัดฝ่าย (เพิ่มให้ฝ่ายตัวเอง) และ Admin           |
| แก้ไข / ลบรายการ                       | ทีมงานของฝ่ายเจ้าของรายการ และ Admin                       |
| ย้ายรายการไปเป็นของฝ่ายอื่น             | Admin เท่านั้น                                             |
| ฝ่ายที่ทำงานร่วมกัน                     | เห็นรายการในปฏิทินของตัวเอง แต่แก้ไขไม่ได้                  |

<Callout type="warn" title="มีคนแก้ไขรายการนี้ก่อนคุณ">
  ถ้าเห็นข้อความนี้ตอนบันทึก แปลว่ามีคนแก้รายการเดียวกันระหว่างที่คุณเปิดค้างไว้ ระบบโหลดข้อมูลล่าสุดให้แล้ว
  ตรวจดูแล้วแก้ใหม่อีกครั้ง ข้อมูลของอีกคนจะไม่ถูกเขียนทับ
</Callout>
