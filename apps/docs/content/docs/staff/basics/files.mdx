<PageHero spot="camera">
  ทุกบัญชีมี **คลังไฟล์** ส่วนตัว ใช้เก็บรูปที่ใช้ในระบบ เช่น รูปโปรไฟล์ รูปในเนื้อหากิจกรรม และรูปในอีเมล
  คลังไฟล์ไม่มีหน้าแยก แต่จะเปิดขึ้นเมื่อคุณกดเลือกรูปในแบบฟอร์มต่าง ๆ
</PageHero>

## เปิดคลังไฟล์

คลังไฟล์ (**ไฟล์ของฉัน**) เปิดจาก

- ช่องเลือกรูปโปรไฟล์ในหน้าลงทะเบียน
- ปุ่มแทรกรูปในตัวแก้ไขเนื้อหา (เนื้อหากิจกรรม อีเมล)
- ช่องใส่ URL รูป เช่น รูปปกกิจกรรม

กด **อัปโหลดไฟล์** หรือเลือกไฟล์ที่เคยอัปโหลดไว้ ด้านล่างแสดง **ใช้พื้นที่ X / Y**

## ขีดจำกัด

| รายการ                     | ค่า                       |
| -------------------------- | ------------------------- |
| พื้นที่ต่อบัญชี (ค่าเริ่มต้น) | 1 GB                      |
| ขนาดไฟล์สูงสุด              | 50 MB (รูปโปรไฟล์ 10 MB)  |
| จำนวนไฟล์ต่อบัญชี            | 1,000 ไฟล์                |
| อัปโหลดค้างพร้อมกัน          | 10 รายการ                 |

<Callout title="พื้นที่ไม่พอ?">
  ลบไฟล์ที่ไม่ใช้ในคลังไฟล์ หรือขอเพิ่มโควตาจาก Admin หรือหัวหน้า/รองหัวหน้าฝ่าย Tech/Live หรือทะเบียน
  ซึ่งปรับได้ในหน้า [ผู้ใช้](/docs/staff/tasks/users#โควตาพื้นที่จัดเก็บ) (ตั้งเป็น 0 เพื่อหยุดอัปโหลดใหม่)
</Callout>
