  เบอร์โทรและช่องทางติดต่อถูกซ่อนไว้ ต้องกดเปิดดูทีละคน

## ค้นหา

เลือกฝ่ายจากตัวกรอง **ทุกฝ่าย** หรือพิมพ์ในช่อง **ค้นหาชื่อ ชื่อเล่น หรือฝ่าย** (กด `⌘K` / `Ctrl K` เพื่อไปที่ช่องค้นหา)

## เปิดดูช่องทางติดต่อ

กดไอคอนบัตรรายชื่อทางขวาของแต่ละคน เพื่อดูเบอร์โทรและโซเชียล

| คุณเป็น                          | เปิดดูได้                         |
| -------------------------------- | --------------------------------- |
| สตาฟ                             | เฉพาะหัวหน้า/รองหัวหน้าฝ่ายตัวเอง |
| หัวหน้าหรือรองหัวหน้าฝ่ายใดก็ได้  | ทุกฝ่าย                           |
| Admin                            | ทุกฝ่าย                           |

<Callout type="warn" title="ทุกครั้งที่เปิดดูจะถูกบันทึก">
  ระบบเก็บประวัติว่าใครเปิดดูช่องทางติดต่อของใครเมื่อไร เพื่อปกป้องข้อมูลส่วนตัวของหัวหน้าฝ่าย
  เปิดดูเฉพาะเมื่อจำเป็นต้องติดต่อเท่านั้น และห้ามนำไปเผยแพร่ต่อ
</Callout>

## แก้ไขข้อมูลของตัวเอง

ถ้าคุณเป็นหัวหน้าหรือรองหัวหน้า จะมีปุ่มดินสอที่ชื่อของคุณ ใช้แก้ชื่อเล่น เบอร์โทร และช่องทางติดต่อของที่นั่งตัวเองได้
ดูขั้นตอนที่ [หัวหน้าฝ่ายอื่น ๆ](/docs/staff/departments/others/leader) ส่วนการเพิ่มหรือลบที่นั่ง ดูที่
[จัดการที่นั่งหัวหน้าฝ่าย](/docs/staff/tasks/leadership)
