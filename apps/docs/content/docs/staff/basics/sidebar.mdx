  ทุกฝ่ายใช้หน้าจอระบบทีมงานแบบเดียวกัน เมนูด้านซ้ายแบ่งเป็นกลุ่ม และจะแสดงเฉพาะเมนูที่คุณมีสิทธิ์
  ถ้าไม่เห็นเมนูไหน แปลว่าบัญชีของคุณยังไม่มีสิทธิ์นั้น ไม่ใช่ระบบเสีย
</PageHero>

## เข้าระบบทีมงาน

- หลังเข้าสู่ระบบ ทีมงานจะถูกพาไปที่ **หน้าหลัก** (`/staff/dashboard`) โดยอัตโนมัติ
- จากหน้าเว็บผู้เข้าร่วม กดรูปของคุณมุมขวาบน แล้วเลือก **ระบบทีมงาน**

<Screenshot src="art-staff/dashboard" alt="หน้าจอระบบทีมงาน" caption="หน้าจอของสตาฟฝ่าย Art" />

## กลุ่มเมนู

| กลุ่ม        | เมนู                                    | ใครเห็น                                                  |
| ------------ | --------------------------------------- | -------------------------------------------------------- |
| ภาพรวม       | หน้าหลัก · ปฏิทิน · หัวหน้าฝ่าย           | ทีมงานทุกคน                                               |
| การจัดการ    | ผู้ใช้                                   | Admin, ฝ่าย Tech/Live และฝ่ายทะเบียน                      |
|              | ฝ่าย                                    | Admin และหัวหน้า/รองหัวหน้าฝ่ายทะเบียน                    |
| กีฬา         | กิจกรรม · ประเภทกีฬา · สถานที่            | ผู้ที่มีสิทธิ์ใดก็ได้ในระบบกีฬา (Tech/Live, ทะเบียน, กีฬา สจล., Admin) |
|              | นักกีฬา                                 | ผู้ที่ดูรายชื่อนักกีฬาได้ (Tech/Live, ทะเบียน, Admin)          |
|              | ทีมแข่ง · แมตช์                         | ผู้ที่ดูระบบแข่งขันได้ (Tech/Live, ทะเบียน สจล., กีฬา สจล., Admin) |
|              | รายงานตัวแข่งขัน                         | ผู้ที่เช็คอินนักกีฬาเข้าแมตช์ได้ (Tech/Live, ทะเบียน สจล., หัวหน้า/รองหัวหน้ากีฬา, Admin) |
| เครื่องมือ   | QR Code · ลิงก์สั้น                     | ทีมงานทุกคน                                               |
|              | ส่งอีเมล                                | Admin, ฝ่าย Tech/Live และหัวหน้า/รองหัวหน้าฝ่ายทะเบียน     |

ดูตารางเต็มแยกตามตำแหน่งได้ที่ [บทบาทและสิทธิ์](/docs/staff/overview#เมนูที่แต่ละตำแหน่งเห็น)

## แถบด้านบน

- ปุ่ม **ซ่อน/แสดงเมนู** ซ้ายบน (บนมือถือเมนูจะเป็นแถบเลื่อนออกมา)
- **เส้นทาง** บอกว่าตอนนี้อยู่หน้าไหน
- **กระดิ่ง** การแจ้งเตือนเมื่อมีการเพิ่ม แก้ไข หรือยกเลิกรายการปฏิทินที่เกี่ยวกับคุณหรือแผนกของคุณ
  กด “โหลดการแจ้งเตือนเก่ากว่านี้” เพื่อดูย้อนหลัง

## เมนูบัญชี

กดชื่อของคุณที่มุมซ้ายล่าง ใต้ชื่อจะบอกตำแหน่งและฝ่าย เช่น “Staff · Art” หรือ “หัวหน้าฝ่าย · Tech/Live”
เมนูนี้มีลิงก์ไป **โปรไฟล์ของฉัน** **ตั๋วของฉัน** **กิจกรรม** **หน้าแรก** และ **ออกจากระบบ**
