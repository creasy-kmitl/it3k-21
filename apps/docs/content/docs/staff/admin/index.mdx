<PageHero spot="server">
  **Admin** ทำได้ทุกอย่างในระบบ ไม่ว่าจะสังกัดฝ่ายไหน และเห็นข้อมูลของทุกสถาบัน
  บัญชี Admin ควรมีน้อยที่สุด และใช้เท่าที่จำเป็น
</PageHero>

## เมนูที่คุณจะเห็น

<Screenshot src="admin/sidebar" alt="เมนูของผู้ดูแลระบบ" />

ครบทุกเมนู และในเมนูบัญชีจะมี **จำลองมุมมอง…** เพิ่มขึ้นมา

## งานที่มีแต่ Admin ทำได้

| งาน                                       | ที่ไหน                                                   |
| ----------------------------------------- | -------------------------------------------------------- |
| ให้หรือถอนสถานะ Admin                       | [ผู้ใช้](/docs/staff/tasks/users)                          |
| แก้ไขบัญชีของ Admin คนอื่น                  | [ผู้ใช้](/docs/staff/tasks/users)                          |
| ย้ายรายการปฏิทินไปเป็นของฝ่ายอื่น              | [ปฏิทิน](/docs/staff/basics/calendar)                       |
| จำลองมุมมองของบทบาทหรือฝ่ายอื่น               | [จำลองมุมมองและดูในฐานะผู้ใช้](/docs/staff/admin/view-as)     |
| ดูในฐานะผู้ใช้ (สวมบัญชี)                     | [จำลองมุมมองและดูในฐานะผู้ใช้](/docs/staff/admin/view-as)     |

งานอื่นทั้งหมด (ที่นั่งหัวหน้า ฝ่าย ระบบกีฬา อีเมล) Admin ทำได้ เหมือนหัวหน้าฝ่าย Tech/Live และทะเบียน

<Screenshot src="admin/users" alt="หน้าผู้ใช้ในมุมมองของ Admin" />

<Callout type="warn" title="ใช้สิทธิ์อย่างระวัง">
  การเปิดดูช่องทางติดต่อหัวหน้าฝ่าย และการสวมบัญชีผู้อื่น ถูกบันทึกไว้พร้อมชื่อ Admin ที่ทำ
</Callout>
