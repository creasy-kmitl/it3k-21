<PageHero spot="camera">
  เมื่อมีคนแจ้งว่า “ไม่เห็นเมนู” หรือ “กดแล้วไม่ได้” Admin ตรวจได้สองแบบ
  **จำลองมุมมอง** ดูหน้าจอของบทบาทและฝ่ายใดก็ได้แบบดูอย่างเดียว และ **ดูในฐานะผู้ใช้** สวมบัญชีของคนนั้นจริง ๆ
</PageHero>

| ต่างกันอย่างไร        | จำลองมุมมอง                         | ดูในฐานะผู้ใช้                                      |
| ------------------- | ---------------------------------- | -------------------------------------------------- |
| ใช้เมื่อ              | อยากรู้ว่าบทบาท/ฝ่ายหนึ่งเห็นอะไร       | ต้องดูข้อมูลของบัญชีนั้นจริง ๆ                         |
| เปิดจาก             | เมนูบัญชี → **จำลองมุมมอง…**          | หน้าผู้ใช้ → **ดูในฐานะผู้ใช้นี้**                     |
| แก้ไขข้อมูลได้        | ไม่ได้ (ดูอย่างเดียว)                  | ได้ ทุกการแก้ไขจะบันทึกว่าคุณเป็นผู้ทำ                   |
| ระยะเวลา            | จนกว่าจะกดออก                        | สูงสุด 1 ชั่วโมง                                     |

## จำลองมุมมอง

<Steps>
<Step>

### เปิดเมนูบัญชี แล้วกด “จำลองมุมมอง…”

</Step>
<Step>

### เลือกบทบาท ฝ่าย และสถาบัน

สถาบันมีผลกับสิ่งที่ฝ่ายทะเบียนและนักกีฬาเห็นในระบบกีฬา

</Step>
<Step>

### ดูหน้าจอ แล้วกด “ออกจากโหมดจำลอง”

แถบด้านบนจะเขียนว่า “กำลังจำลองมุมมอง: … (ดูอย่างเดียว)” ตลอดเวลา

</Step>
</Steps>

## ดูในฐานะผู้ใช้

<Steps>
<Step>

### ในหน้า “ผู้ใช้” กด “ดูในฐานะผู้ใช้นี้” ที่แถวของบัญชีนั้น

</Step>
<Step>

### ตรวจปัญหา

แถบด้านบนจะเขียนว่า “คุณกำลังใช้บัญชีของ … · ทุกการแก้ไขจะบันทึกว่าคุณเป็นผู้ทำ”

</Step>
<Step>

### กด “กลับสู่บัญชีของฉัน”

ถ้าครบ 1 ชั่วโมง ระบบจะแจ้งว่าหมดเวลาสวมบัญชี ให้กดกลับเช่นกัน

</Step>
</Steps>
