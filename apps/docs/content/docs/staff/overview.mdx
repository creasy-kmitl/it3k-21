## บทบาทของบัญชี

| บทบาท         | ความหมาย                                       |
| ------------- | ---------------------------------------------- |
| `guest`       | บัญชีใหม่ที่เพิ่งเข้าสู่ระบบ ยังไม่มีสิทธิ์ใดๆ |
| `participant` | ผู้เข้าร่วมงาน                                 |
| `athlete`     | นักกีฬา                                        |
| `staff`       | สตาฟ เข้าหน้า `/staff` ได้                     |
| `admin`       | ผู้ดูแลระบบ มีสิทธิ์ทุกอย่าง                   |

## หัวหน้าและรองหัวหน้าฝ่าย

หัวหน้าและรองหัวหน้าไม่ใช่บทบาท แต่เป็น **ที่นั่ง** ของฝ่าย ที่นั่งมีได้เฉพาะบัญชีของ สจล.
บัญชีของสถาบันอื่นเป็นสตาฟได้ แต่นั่งตำแหน่งหัวหน้าหรือรองหัวหน้าไม่ได้

หัวหน้าและรองหัวหน้าของฝ่าย Tech/Live และฝ่ายทะเบียน (สจล.) มีสิทธิ์เต็ม เช่น ให้บทบาทอื่นๆ
จัดการที่นั่ง และดูแลระบบกีฬาทั้งหมด
