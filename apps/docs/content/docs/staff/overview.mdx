  ระบบทีมงาน (`/staff`) แสดงเมนูไม่เหมือนกันในแต่ละคน ขึ้นกับ **บทบาท** **ฝ่าย** และ **ที่นั่ง** ของบัญชี
  หน้านี้อธิบายว่าทั้งสามอย่างคืออะไร แล้วพาไปยังคู่มือของฝ่ายและตำแหน่งของคุณ

## 1. บทบาทของบัญชี

| บทบาท                | ชื่อที่เห็นในระบบ | ความหมาย                                                               |
| -------------------- | ---------------- | ---------------------------------------------------------------------- |
| `guest`              | Guest            | บัญชีใหม่ ยังไม่ได้กรอกโปรไฟล์ ยังไม่มีสิทธิ์ใด ๆ                       |
| `participant`        | ผู้เข้าร่วม       | ส่งโปรไฟล์แล้ว รับตั๋วกิจกรรมได้                                       |
| `athlete`            | นักกีฬา          | สมัครแข่งกีฬาในนามสถาบันได้                                            |
| `staff`              | Staff            | เข้าระบบทีมงานได้ สิทธิ์เพิ่มเติมขึ้นกับฝ่ายและที่นั่ง                   |
| `admin`              | Admin            | ผู้ดูแลระบบ ทำได้ทุกอย่าง                                              |

บัญชีหนึ่งมีได้หลายบทบาทพร้อมกัน เช่น ผู้เข้าร่วมที่เป็นนักกีฬาด้วย เฉพาะ **Staff** และ **Admin** เท่านั้นที่เข้าระบบทีมงานได้
นักกีฬาหรือผู้เข้าร่วมที่เปิดลิงก์ระบบทีมงานจะถูกพาไปหน้าโปรไฟล์หรือหน้ารอสิทธิ์แทน

## 2. ฝ่ายที่สังกัด

งานมีทั้งหมด 16 ฝ่าย แต่มีเพียง 2 ฝ่ายที่ได้ **สิทธิ์พิเศษ** ในระบบ

| ฝ่าย           | สิทธิ์พิเศษ                                                                           |
| -------------- | ------------------------------------------------------------------------------------- |
| **Tech/Live**  | ดูแลบัญชีผู้ใช้ แก้ไขลิงก์สั้นของทุกคน ดูแลระบบกีฬาและเช็คอิน ส่งอีเมลถึงผู้เข้าร่วม     |
| **ทะเบียน**    | ดูแลบัญชีผู้ใช้ ดูแลนักกีฬาและสถาบันของบัญชี หัวหน้าส่งอีเมลและจัดการรายชื่อฝ่ายได้       |
| อีก 14 ฝ่าย    | สิทธิ์พื้นฐานเท่ากันทุกฝ่าย: ปฏิทิน รายชื่อหัวหน้าฝ่าย QR Code และลิงก์สั้น               |

สิทธิ์พิเศษผูกกับ **รหัสฝ่าย** ที่ตั้งไว้ถาวร (`tech-live` และ `registration`) ไม่ใช่ชื่อฝ่าย
เปลี่ยนชื่อฝ่ายแล้วสิทธิ์ก็ยังอยู่ และสร้างฝ่ายใหม่ชื่อเดียวกันก็ไม่ได้สิทธิ์นั้น

## 3. ที่นั่งหัวหน้าและรองหัวหน้า

หัวหน้าและรองหัวหน้าฝ่ายไม่ใช่บทบาท แต่เป็น **ที่นั่ง** ของฝ่าย แต่ละฝ่ายมีหัวหน้า 1 ที่นั่งและรองหัวหน้า 1 ที่นั่ง
ผู้ที่นั่งยังมีบทบาทเป็น Staff เหมือนเดิม แต่ได้สิทธิ์เพิ่มตามฝ่ายของที่นั่ง

<Callout type="warn" title="ที่นั่งมีได้เฉพาะบัญชีของ สจล.">
  สจล. เป็นเจ้าภาพ จึงมีเพียงบัญชีของ สจล. (หรือบัญชีที่ยังไม่ได้ระบุสถาบัน ซึ่งจะกลายเป็นของ สจล. เมื่อได้ที่นั่ง)
  ที่นั่งตำแหน่งได้ บัญชีของสถาบันอื่นเป็นสตาฟได้ แต่ได้ที่นั่งไม่ได้
</Callout>
