  หน้า **ผู้ใช้** (`/staff/users`) ใช้กำหนดสถานะ Guest ผู้เข้าร่วม นักกีฬา Staff หรือหัวหน้าฝ่าย และพื้นที่จัดเก็บไฟล์
  เปิดได้เฉพาะ Admin ฝ่าย Tech/Live และฝ่ายทะเบียน
</PageHero>

## ใครทำอะไรได้

| คุณเป็น                                                     | สถานะที่ให้ได้                                  | ตั้งสถาบัน | โควตา |
| ----------------------------------------------------------- | ---------------------------------------------- | :-------: | :---: |
| Admin                                                       | ทุกสถานะ รวม Admin                              | ✓         | ✓     |
| หัวหน้า/รองหัวหน้า Tech/Live หรือทะเบียน (สจล.)               | ทุกสถานะ ยกเว้น Admin                            | ✓         | ✓     |
| สตาฟทะเบียน สจล.                                             | Guest (เฉพาะบัญชีที่ยังไม่ใช่ทีมงาน)                | ✓         |       |
| สตาฟ Tech/Live และสตาฟทะเบียนสถาบันอื่น                        | Guest (เฉพาะบัญชีที่ยังไม่ใช่ทีมงาน)                |           |       |

“ทีมงาน” ในที่นี้หมายถึงบัญชีที่เป็น Staff หรือ Admin บัญชีของ Admin แก้ได้โดย Admin เท่านั้น

## ค้นหาบัญชี

พิมพ์ในช่อง **ค้นหาชื่อ** หรือกรองตาม **ฝ่าย** แต่ละแถวบอกชื่อ อีเมล สถานะ ฝ่าย และสถาบัน

## แก้ไขบัญชี

<Steps>
<Step>

### กดปุ่มดินสอท้ายแถว

ถ้าไม่มีปุ่ม แปลว่าคุณไม่มีสิทธิ์แก้บัญชีนั้น

</Step>
<Step>

### เลือก “สถานะ”

| สถานะ               | ต้องเลือกฝ่าย | ผลที่ได้                                               |
| ------------------- | :----------: | ------------------------------------------------------ |
| Guest               |              | ถอนสิทธิ์ทั้งหมด                                         |
| ผู้เข้าร่วม          |              | รับตั๋วได้                                              |
| นักกีฬา             |              | สมัครกีฬาได้                                            |
| Staff               | ✓            | เข้าระบบทีมงาน สังกัดฝ่ายที่เลือก                         |
| หัวหน้าฝ่าย / รองหัวหน้าฝ่าย | ✓    | Staff + ได้ที่นั่งของฝ่ายนั้น (เฉพาะบัญชีของ สจล.)        |

</Step>
<Step>

### ตั้ง “สถาบัน” (ถ้ามีสิทธิ์)

ใช้กำหนดว่าฝ่ายทะเบียนเห็นนักกีฬาของสถาบันใด

</Step>
<Step>

### บันทึก

</Step>
</Steps>

<Callout type="warn" title="เปลี่ยนสถานะคนที่มีที่นั่ง">
  ถ้าบัญชีมีที่นั่งหัวหน้า/รองหัวหน้าอยู่ แล้วคุณเลือกสถานะอื่น ที่นั่งนั้นจะถูกลบพร้อมช่องทางติดต่อ
  และถ้าให้ที่นั่งที่มีคนอยู่แล้ว คนเดิมจะหลุดจากที่นั่งนั้น
</Callout>

## โควตาพื้นที่จัดเก็บ

ช่อง **พื้นที่จัดเก็บสูงสุด (GB)** แสดงพื้นที่ที่ใช้ไปแล้ว ค่าเริ่มต้นคือ 1 GB ตั้งเป็น `0` เพื่อหยุดอัปโหลดใหม่
ไฟล์เดิมยังอยู่ จะอัปโหลดเพิ่มได้เมื่อใช้พื้นที่ต่ำกว่าโควตา

## ไม่เจอคนที่ต้องการ?

บัญชีจะเกิดขึ้นเมื่อคนนั้นเข้าสู่ระบบด้วย Google ครั้งแรก ถ้าเขาไม่ได้ใช้อีเมล สจล. มจธ. หรือ มจพ.
ต้อง [เชิญ](/docs/staff/tasks/invitations) ก่อน
