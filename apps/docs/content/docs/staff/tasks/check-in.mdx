## ขั้นตอน

<Steps>
<Step>

### เปิดกล้อง

เบราว์เซอร์จะขออนุญาตใช้กล้อง ให้กดอนุญาต ถ้ามีหลายกล้องใช้ปุ่ม **สลับกล้อง** (Kiosk จำกล้องที่เลือกไว้ให้)
ถ้าไม่มีกล้อง ใช้เครื่องสแกน หรือพิมพ์ **รหัสตั๋วหรือรหัสผู้ใช้** แล้วกด Enter

</Step>
<Step>

### สแกน

ระบบแสดงชื่อ ประเภทตั๋ว (เช่น “ผู้ชมทั่วไป · ใบที่ 2/3”) และข้อมูลนักกีฬา เช่น สถาบัน รหัสนักศึกษา เบอร์เสื้อ

</Step>
<Step>

### สแกนคนถัดไป

กด **สแกนคนถัดไป** (หรือแตะหน้าจอใน Kiosk) บาร์โค้ดเดิมที่ค้างหน้ากล้องจะไม่ถูกนับซ้ำ

</Step>
</Steps>

## ผลการสแกน

| ข้อความ                                   | ความหมาย / สิ่งที่ต้องทำ                                       |
| ---------------------------------------- | ------------------------------------------------------------- |
| เช็คอินสำเร็จ                              | ให้เข้างานได้                                                   |
| เช็คอินไปแล้ว (เมื่อ …)                     | ตั๋วใบนี้ใช้ไปแล้ว ตรวจว่าเป็นเจ้าของตั๋วจริงหรือไม่                    |
| ใช้ตั๋วครบทุกใบแล้ว                          | ผู้ใช้คนนี้เช็คอินครบจำนวนตั๋วที่มีแล้ว                              |
| ยังไม่ได้รับตั๋วกิจกรรมนี้                     | ให้ผู้เข้าร่วมรับตั๋วในหน้า [กิจกรรม](/docs/participants/events-and-tickets) ก่อน |
| ตั๋วนี้เป็นของกิจกรรมอื่น (ชื่อกิจกรรม)         | เปิดผิดกิจกรรม หรือผู้เข้าร่วมเปิดตั๋วผิดใบ                         |
| ไม่พบตั๋วจากรหัสนี้ / ไม่พบผู้ใช้จากรหัสนี้      | สแกนใหม่ หรือพิมพ์รหัสเอง                                        |

## บังคับเช็คอินและยกเลิก

เฉพาะ **Admin และหัวหน้า/รองหัวหน้า Tech/Live หรือทะเบียน**

- **เช็คอินโดยไม่มีตั๋ว** ปุ่มจะขึ้นเมื่อผู้ใช้ยังไม่มีตั๋ว ผลจะแสดงเป็น “เช็คอินแล้ว (บังคับ)”
- **บังคับเช็คอิน** และ **ยกเลิกการเช็คอิน** จากเมนูท้ายแถวในแท็บผู้เข้าร่วม ใช้แก้กรณีสแกนผิดคน

<Callout type="warn" title="Kiosk ต้องเปิดด้วยบัญชีที่มีสิทธิ์">
  ถ้าเห็น “บัญชีนี้ไม่มีสิทธิ์ใช้ Kiosk เช็คอิน” ให้เข้าสู่ระบบด้วยบัญชีสตาฟ Tech/Live หรือทะเบียน สจล.
  อย่าทิ้งเครื่องไว้โดยไม่มีคนดู เพราะเครื่องนั้นเข้าสู่ระบบด้วยบัญชีของคุณ กด **ออก** เมื่อเลิกใช้
</Callout>
