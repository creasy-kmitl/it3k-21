## เปิดหน้าตั้งค่า

ไปที่ **ทีมแข่ง** แล้วกดไอคอนตั้งค่าข้างชื่อประเภท หรือกด **ตั้งค่าการแข่งขัน** ในหน้าจัดทีมของประเภทนั้น

<Screenshot src="tech-head/competition-settings" alt="หน้าตั้งค่าการแข่งของประเภท ส่วนทีม รายชื่อลงแข่ง และการนับคะแนน" />

ผู้ที่จัดตารางแข่งได้ (Tech/Live, หัวหน้า/รองหัวหน้าทะเบียนและกีฬา, Admin) แก้ค่าได้
คนอื่นที่เห็นเมนู **ทีมแข่ง** จะเห็นข้อความ "ดูได้อย่างเดียว ผู้จัดการแข่งขันเท่านั้นที่แก้ไขได้" และกรอกช่องไม่ได้

## ส่วนต่าง ๆ

### ทีม

| ช่อง                   | ใช้ทำอะไร                                                                    |
| ---------------------- | --------------------------------------------------------------------------- |
| ทีมต่อมหาลัย            | จำนวนทีมสูงสุดที่แต่ละมหาลัยส่งได้                                            |
| นักกีฬาขั้นต่ำ / สูงสุด    | จำนวนคนต่อทีม เว้นว่างไว้เพื่อใช้ตามรูปแบบ (เดี่ยว 1 คน คู่ 2 คน)                  |
| ชายอย่างน้อย / หญิงอย่างน้อย | ใช้กับประเภทผสม เช่น ชักเย่อที่ต้องมีชายและหญิงอย่างละ 2 คน                       |
| เจ้าหน้าที่ทีมสูงสุด       | จำนวนเจ้าหน้าที่ทีม (ผู้ฝึกสอน ผู้จัดการทีม) ที่เพิ่มได้                             |

ค่าเหล่านี้คือสิ่งที่กล่อง **สิ่งที่ยังไม่ครบ** ใน [ทีมแข่ง](/docs/staff/tasks/teams) ใช้ตรวจ

### รายชื่อลงแข่ง

**ตัวจริง** และ **ตัวสำรองสูงสุด** ของแต่ละแมตช์ เว้นตัวจริงว่างไว้ถ้าแมตช์ไม่ต้องส่งรายชื่อ ทุกคนในทีมลงได้
รายชื่อลงแข่งจัดในหน้าแมตช์ ดู [แมตช์และสายการแข่ง](/docs/staff/tasks/competition#รายชื่อลงแข่ง)

### การนับคะแนน

ติ๊ก **กำหนดการนับคะแนนเอง** เพื่อแก้ ถ้าไม่ติ๊กจะใช้ค่าตั้งต้นของประเภทนั้น แล้วเลือก **วิธีนับคะแนน**

| วิธีนับคะแนน     | ใช้กับ                         | ตั้งอะไรได้บ้าง                                                                 |
| --------------- | ------------------------------ | ----------------------------------------------------------------------------- |
| นับแต้มสะสม      | ฟุตบอล บาสเกตบอล แชร์บอล       | ปุ่มเพิ่มคะแนน (เช่น 1, 2, 3), จำนวนช่วงและชื่อช่วง, เสมอได้ไหม, ต่อเวลา, ยิงโทษ, แต้มที่ชนะทันที, นาฬิกาจับเวลา |
| แข่งเป็นเซต       | แบดมินตัน เทเบิลเทนนิส Valorant  | แต้มต่อเซต, ต้องห่างอย่างน้อย, แต้มสูงสุด, ชนะกี่เซตจึงชนะแมตช์                    |
| นับเกมที่ชนะ      | ชักเย่อ วิ่งเปรี้ยว ROV           | จำนวนเกม, ชนะกี่ครั้งจึงชนะแมตช์                                                |
| นับแต้มรายเอนด์    | เปตอง                          | แต้มที่ชนะ, แต้มสูงสุดต่อเอนด์                                                    |
| จัดอันดับ         | กรีฑา กินวิบาก TFT               | วัดผลจาก เวลา (น้อยชนะ) ระยะ (มากชนะ) หรืออันดับในแต่ละเกม, จำนวนครั้งต่อฝ่าย, คะแนนตามอันดับ        |

แต่ละแมตช์ตั้งวิธีนับคะแนนของตัวเองทับค่านี้ได้ เช่น ให้รอบชิงเล่นถึง 21 แต้ม ทำได้ในฟอร์มแก้ไขแมตช์

### ตารางคะแนน

ติ๊ก **มีตารางคะแนนรอบแบ่งกลุ่ม** แล้วกำหนดแต้มของ **ชนะ** **เสมอ** **แพ้** และ **ปรับแพ้**
จากนั้นเลือกว่า **เมื่อคะแนนเท่ากัน ตัดสินด้วย** อะไรบ้าง เรียงลำดับได้ด้วยปุ่มเลื่อนขึ้นลง

- ผลการพบกัน
- ผลต่างคะแนนได้-เสีย
- คะแนนได้
- จำนวนครั้งที่ชนะ
- อัตราส่วนเซตได้-เสีย
- อัตราส่วนแต้มได้-เสีย

ตารางนี้แสดงในหน้า [ตารางคะแนน](/docs/participants/results#ตารางคะแนน) สาธารณะ

### มอบเหรียญและคะแนนรวม

ติ๊ก **มอบเหรียญและคะแนนรวม** ถ้าอันดับของประเภทนี้นับเข้าตารางเหรียญ ประเภทที่มีไม่ถึง 3 ทีมเป็นการแข่งขันกระชับมิตร
และไม่นับเหรียญไม่ว่าจะติ๊กหรือไม่

### รายงานตัว

| ช่อง                | ใช้ทำอะไร                                                                      |
| ------------------- | ----------------------------------------------------------------------------- |
| สแกนที่สนาม / เจ้าหน้าที่ติ๊ก | สแกนที่สนาม: นักกีฬาสแกนบาร์โค้ดที่ kiosk ประจำสนาม · เจ้าหน้าที่ติ๊ก: สตาฟติ๊กชื่อเอง (Esports ที่รายงานตัวผ่าน Discord) |
| เปิดก่อนแข่ง (นาที)    | ค่าตั้งต้น 40 นาทีก่อนเวลาแข่ง                                                    |
| ปิดก่อนแข่ง (นาที)     | ค่าตั้งต้น 10 นาทีก่อนเวลาแข่ง หลังปิดแล้วจึงปรับแพ้ฝั่งที่มาไม่ครบได้                       |
| ต้องมาอย่างน้อย (คน)   | ฝั่งที่รายงานตัวไม่ถึงจำนวนนี้ปรับแพ้ได้                                                |

ดูการรายงานตัวทั้งหมดที่ [รายงานตัวแข่งขัน](/docs/staff/tasks/match-checkin)

## บันทึก

แถบล่างขึ้นมาเมื่อมีการแก้ไข กด **บันทึก** แล้วจะเห็น "บันทึกการตั้งค่าแล้ว" ถ้าค่าที่กรอกขัดกัน เช่น
นักกีฬาขั้นต่ำมากกว่าสูงสุด หรือปิดรายงานตัวไม่ทันก่อนเปิด ระบบจะไม่บันทึกและบอกช่องที่ต้องแก้

- ออกจากหน้าก่อนบันทึก ระบบจะถามว่าจะ **ทิ้งการตั้งค่าที่ยังไม่ได้บันทึก** ไหม
- ถ้ามีคนบันทึกประเภทเดียวกันก่อนคุณ ค่าของเขาจะไม่ถูกทับ ให้โหลดหน้าใหม่แล้วแก้อีกครั้ง
