## สร้างแมตช์

ที่หน้า **แมตช์** กด **สร้างแมตช์** แล้วเลือกประเภท ทีมทั้งสองฝั่ง เวลา สนามและคอร์ต สร้างทีละแมตช์
ถ้ายังไม่รู้ว่าทีมไหนจะได้เข้ารอบ เลือกทีมเป็น **ยังไม่รู้ทีม** แล้วเลือกว่าฝั่งนี้มาจากไหน

- **ผู้ชนะ M3** หรือ **ผู้แพ้ M3**: ผูกกับแมตช์ก่อนหน้าในประเภทเดียวกัน พอแมตช์นั้นจบ ระบบใส่ทีมให้เอง
- **ใส่ชื่อชั่วคราวเอง**: เช่น "อันดับ 1 สาย A" แล้วค่อยเปลี่ยนเป็นทีมจริงในหน้าแมตช์

ประเภทที่มีไม่ถึง 3 ทีมจะเป็นนัดกระชับมิตรอัตโนมัติ

## หน้าแมตช์

กดแมตช์ในหน้า **แมตช์** (ทั้งแท็บสายการแข่งและรายการ) เพื่อเปิดหน้าของแมตช์นั้น ด้านบนบอกประเภท รอบ สถานะ เวลา และสนาม

<Screenshot src="tech-head/match-detail" alt="หน้าแมตช์ของทีมงาน มีปุ่มบันทึกคะแนน แก้ไข ลบ เปลี่ยนสถานะ และรายชื่อลงแข่งของแต่ละฝั่ง" />

| ปุ่ม / ส่วน          | ทำอะไร                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| **บันทึกคะแนน**     | เปิดหน้าใส่คะแนน ดู [ใส่คะแนน](/docs/staff/tasks/scoring)                                                   |
| **แก้ไข**           | แก้ทีม เวลา สนาม คอร์ต รอบ หมายเหตุ และวิธีนับคะแนนเฉพาะแมตช์นี้ ด้วยฟอร์มเดียวกับตอนสร้าง                       |
| **ลบ**              | ลบได้เมื่อแมตช์ยังไม่เริ่ม ผู้แข่ง กรรมการ และรูปของแมตช์นี้ถูกลบด้วย                                           |
| **สถานะ**           | **เปลี่ยนสถานะ** เป็น ยังไม่เริ่ม · เปิดรายงานตัว · เลื่อน · ยกเลิก (กำลังแข่งและจบแล้ว เปลี่ยนจากหน้าใส่คะแนน) |
| **ผู้แข่ง**          | ทีมของแต่ละฝั่ง ฝั่งที่ยังเป็นชื่อชั่วคราว เลือก **ทีมที่เข้ามาแทน** ได้ ชื่อเดิมเก็บไว้เป็นประวัติ                     |
| **กรรมการ**         | **เพิ่มกรรมการ** พร้อม **หน้าที่** เช่น ผู้ตัดสิน ผู้กำกับเส้น แก้ชื่อหรือลบได้ แสดงในหน้าแมตช์สาธารณะ               |
| **รูปภาพ**          | **เพิ่มรูป** พร้อมคำบรรยาย แสดงในหน้าแมตช์สาธารณะ                                                         |

ปุ่มแก้ไข ลบ สถานะ ทีม กรรมการ และรูป มีเฉพาะคนที่จัดตารางแข่งได้ ส่วน **บันทึกคะแนน** มีสำหรับทุกคนที่ใส่คะแนนได้

### รายชื่อลงแข่ง

ประเภทที่กำหนดจำนวนตัวจริงไว้ (ดู [ตั้งค่าการแข่งของประเภท](/docs/staff/tasks/competition-settings#รายชื่อลงแข่ง)) จะมีรายชื่อนักกีฬาของแต่ละฝั่งในหน้าแมตช์
เลือกแต่ละคนเป็น **ไม่ลง** **ตัวจริง** หรือ **ตัวสำรอง** แล้วกด **บันทึกรายชื่อ** หัวรายการนับให้ เช่น "ตัวจริง 5 / 5 · สำรอง 3 / 7"
เลือกเกินจำนวนที่กำหนดไม่ได้

รายชื่อนี้ใช้ต่อในหลายที่

- kiosk รายงานตัวรับเฉพาะนักกีฬาในรายชื่อ ("ไม่อยู่ในรายชื่อผู้เล่นของแมตช์นี้ ติดต่อผู้จัดการทีม")
- หน้าใส่คะแนนใช้เลือกผู้ทำแต้ม
- หน้าแมตช์สาธารณะแสดงตัวจริงและตัวสำรองพร้อมเบอร์เสื้อ (แสดงแค่ชื่อ ไม่มีนามสกุลหรืออีเมล)

แมตช์ที่มีรายชื่อลงแข่งหรือมีคนรายงานตัวแล้ว ทีมจะไม่เลื่อนเข้ามาตามสายการแข่งเอง (ดูเงื่อนไขท้ายหน้า)

## ดูสายการแข่ง

หน้า **แมตช์** เปิดมาที่แท็บ **สายการแข่ง** ซึ่งแสดงแมตช์ที่ผูกผู้ชนะหรือผู้แพ้ไว้เป็นสายน็อกเอาต์ (ดูทุกแมตช์แบ่งตามวันได้ที่แท็บ **รายการ**) เรียงจากรอบแรกทางซ้ายไปนัดชิงทางขวา แยกตามประเภท กดการ์ดเพื่อเปิดแมตช์นั้น
หน้าผลการแข่งขันสาธารณะ (`/matches`) ก็มีแท็บ **สายการแข่ง** ให้ทุกคนดูได้ แต่ไม่มีปุ่มเพิ่มแมตช์

- ประเภทที่ไม่มีแมตช์ไหนผูกกันจะไม่ขึ้นในสาย
- นัดชิงอันดับ 3 (ผูกกับผู้แพ้) แสดงเป็นอีกสายใต้นัดชิง
- มุมมองนี้กรองได้แค่กีฬาและประเภท เพราะสายต้องเห็นครบทุกแมตช์

<Screenshot src="tech-head/matches-bracket" alt="แท็บสายการแข่ง รอบรองชนะเลิศต่อเส้นไปนัดชิง และนัดชิงอันดับ 3 แยกด้านล่าง" />

<Screenshot src="public/matches-bracket" alt="สายการแข่งในหน้าผลการแข่งขันสาธารณะ" />

ผู้ที่จัดการแมตช์ได้จะเพิ่มแมตช์จากหน้านี้ได้เลย

- **เพิ่มสายการแข่ง** (ปุ่มด้านบน): เลือกประเภท จำนวนทีม (4, 8 หรือ 16) และจะมีนัดชิงอันดับ 3 ไหม ระบบสร้างแมตช์ทั้งสายพร้อมผูกผู้ชนะต่อกันให้ รอบแรกตั้งชื่อเป็น "ทีมที่ 1", "ทีมที่ 2" ไว้ก่อน แล้วค่อยเปิดแต่ละแมตช์เพื่อใส่ทีม เวลา และสนาม
- **+ ที่ขอบขวาของการ์ด**: ต่อรอบถัดไป เปิดฟอร์มสร้างแมตช์ที่ฝั่ง 1 เป็นผู้ชนะของแมตช์นั้นไว้ให้ มีเฉพาะแมตช์สุดท้ายของแต่ละสาย
- **+ หน้าฝั่งที่ยังไม่รู้ทีม**: เพิ่มแมตช์ก่อนหน้า สร้างแมตช์ใหม่แล้วส่งผู้ชนะเข้าฝั่งนั้นให้ในครั้งเดียว
- **เพิ่มนัดชิงอันดับ 3** (ใต้การ์ดนัดชิง): สร้างนัดที่ผู้แพ้ของสองแมตช์ที่ส่งเข้าชิงมาพบกัน

<Screenshot src="tech-head/bracket-builder" alt="หน้าต่างเพิ่มสายการแข่ง เลือกประเภท จำนวนทีม และนัดชิงอันดับ 3" />

ทีมจะเลื่อนเข้าแมตช์ถัดไปเองเมื่อแมตช์ก่อนหน้าจบ โดยมีเงื่อนไขดังนี้

- แมตช์ถัดไปต้องยังไม่เริ่ม ยังไม่มีรายชื่อลงแข่งหรือคนรายงานตัว ถ้ามีแล้ว ให้เปลี่ยนทีมเองในหน้าแมตช์
- ผลเสมอไม่เลื่อนใคร ต้องเลือกทีมเอง
- แก้ผลแมตช์ก่อนหน้าทีหลัง ทีมในแมตช์ถัดไปจะเปลี่ยนตาม ตราบใดที่แมตช์ถัดไปยังไม่เริ่ม
