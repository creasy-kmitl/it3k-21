## ใครใส่คะแนนได้

Tech/Live, ทะเบียน สจล., ฝ่ายกีฬา สจล. (ทั้งสตาฟและหัวหน้า) และ Admin บัญชีอื่นจะเห็น "บัญชีนี้ไม่มีสิทธิ์ใส่คะแนน"

## เปิดหน้าใส่คะแนน

เปิดแมตช์จากหน้า **แมตช์** แล้วกด **บันทึกคะแนน** หน้าใส่คะแนนอยู่ที่ `/score/<รหัสแมตช์>` ส่งลิงก์ให้คนที่ยืนข้างสนามเปิดได้เลย
(ต้องเข้าสู่ระบบด้วยบัญชีที่ใส่คะแนนได้)

- ด้านบนบอกกีฬา ประเภท รอบ หมายเลขแมตช์ คอร์ต และสถานะ
- หน้าจอไม่ดับเองระหว่างเปิดหน้านี้ จะได้ไม่ต้องปลดล็อกบ่อย
- ใช้มือถือแนวนอนจะเห็นสองฝั่งข้างกัน
- เปิดหน้าเดียวกันหลายเครื่องได้ คะแนนที่อีกเครื่องกดจะขึ้นตาม

## ขั้นตอน

<Steps>
<Step>

### กด “เริ่มแข่ง”

สถานะเปลี่ยนเป็น **กำลังแข่ง** ถ้าลืมกด การกดคะแนนครั้งแรกจะเริ่มแมตช์ให้เอง

</Step>
<Step>

### กดคะแนนของแต่ละฝั่ง

ปุ่มต่างกันตามวิธีนับคะแนนของประเภท (ดูตารางด้านล่าง) กดผิดให้กด **ยกเลิก** ใต้ฝั่งนั้น
หรือ **ยกเลิกรายการล่าสุด** ที่แถบล่างเพื่อถอยรายการล่าสุดของทั้งแมตช์ **รายการล่าสุด** ใต้แถบแสดง 8 รายการหลังสุด

</Step>
<Step>

### กด “จบแมตช์”

เมื่อได้ผลตามกติกา จะขึ้น **ได้ผลตามกติกาแล้ว** และปุ่มจบแมตช์เป็นสีเข้ม กดแล้วยืนยัน ผลจะขึ้นหน้าสาธารณะและตารางคะแนน
ถ้ายังไม่มีผลแพ้ชนะตามกติกา (เช่น หมดเวลาตอนเสมอในแมตช์ที่เสมอไม่ได้) ระบบจะเตือนก่อน และมีปุ่ม **จบตามคะแนนตอนนี้**
ให้จัดอันดับตามคะแนนที่มีอยู่

</Step>
</Steps>

พอแมตช์จบ ทีมผู้ชนะหรือผู้แพ้จะเลื่อนเข้าแมตช์ถัดไปในสายการแข่งเอง ดูเงื่อนไขที่ [แมตช์และสายการแข่ง](/docs/staff/tasks/competition#ดูสายการแข่ง)

## แต่ละวิธีนับคะแนน

| วิธีนับคะแนน  | สิ่งที่เห็นบนจอ                                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------------- |
| นับแต้มสะสม   | ปุ่ม **+1** (บาสเกตบอลมี +1 +2 +3) แยกตามช่วง เช่น **ครึ่งที่ 1** และปุ่ม **จบครึ่งที่ 1** เพื่อไปช่วงถัดไป มีปุ่มนับ **ฟาวล์** และ **เวลานอก** ของแต่ละฝั่ง ถ้ากติกามีต่อเวลาหรือยิงโทษ (เช่น ดวลจุดโทษ) จะมีช่วงนั้นต่อจากช่วงปกติ ช่วงยิงโทษกดว่าแต่ละลูกเข้าหรือ **ไม่เข้า** |
| แข่งเป็นเซต    | แต้มของเซตปัจจุบัน เช่น **เกมที่ 1** ถึงแต้มชนะ (และห่างพอตามกติกา) แล้วขึ้นเซตถัดไปเอง ชนะครบจำนวนเซตแล้วได้ผล              |
| นับเกมที่ชนะ   | **เกมที่ 1 จาก 3** กดฝั่งที่ชนะแต่ละเกม ชนะเกินครึ่งแล้วได้ผล                                                               |
| นับแต้มรายเอนด์ | **เอนด์ที่ N** เลือกฝั่งที่ได้แต้มและจำนวนแต้มของเอนด์นั้น หรือ **เอนด์นี้ไม่มีคะแนน** ถึงแต้มชนะ (เปตอง 13) แล้วได้ผล        |
| จัดอันดับ      | ช่องกรอกผลของแต่ละฝ่าย แล้วกด **บันทึก** ระบบเรียงอันดับให้                                                                |

### นาฬิกาจับเวลา

ประเภทที่เปิด **ใช้นาฬิกาจับเวลา** (เช่น ฟุตบอล บาสเกตบอล) มี **เวลาที่เหลือ** พร้อมปุ่ม **เดินเวลา** **หยุดเวลา** และ **ตั้งเวลาใหม่**
หมดเวลาแล้วนาฬิกาขึ้น **หมดเวลา** ให้กดจบช่วงหรือจบแมตช์เอง

### ระบุผู้ทำแต้ม

ติ๊ก **ระบุผู้ทำแต้ม** ที่แถบล่าง แล้วทุกครั้งที่กดคะแนนจะให้เลือกเบอร์เสื้อของผู้ทำแต้มจากรายชื่อลงแข่ง (หรือทีมถ้าไม่มีรายชื่อ)
กด **ไม่ระบุ** เพื่อข้ามได้ ชื่อและเบอร์เสื้อจะขึ้นในไทม์ไลน์ของหน้าแมตช์สาธารณะ ใช้ได้กับแต้มสะสม เซต และเอนด์

### จัดอันดับ: กรอกเวลาหรือระยะ

- เวลา: พิมพ์เป็นวินาที เช่น `10.98` หรือนาทีกับวินาที เช่น `1:02.35`
- ระยะ: พิมพ์เป็นเมตร เช่น `6.45`
- ฝ่ายที่ไม่ได้ลงหรือไม่จบ กด **DNS** (ไม่ได้ลงแข่ง) **DNF** (ไม่จบ) หรือ **DQ** (ถูกตัดสิทธิ์)
- ประเภทที่แข่งหลายเกม (เช่น TFT) เลือกเกมก่อนแล้วใส่อันดับของแต่ละฝ่าย

## ตอนเน็ตหลุด

กดคะแนนต่อได้ตามปกติ ด้านบนจะมีป้าย **ออฟไลน์ · รอส่ง N** พอกลับมาออนไลน์ป้ายเปลี่ยนเป็น **กำลังส่ง** แล้วหายไปเมื่อส่งครบ
ระบบไม่นับซ้ำ แม้ส่งรายการเดิมสองครั้ง อย่าปิดหน้านี้ระหว่างที่ยังมีรายการรอส่ง

ถ้ามีรายการที่ส่งไม่ได้ จะขึ้นว่า "ไม่ได้บันทึกบางรายการ" พร้อมเหตุผล เช่น แมตช์ถูกจบจากเครื่องอื่นไปแล้ว

## ผลพิเศษ

กด **ผลพิเศษ** เมื่อแมตช์ไม่ได้แข่งตามปกติ หรือต้องแก้ผลที่บันทึกไปแล้ว (แก้ได้แม้แมตช์จบแล้ว)

| ผลการแข่งขัน     | ใช้เมื่อ                                     | ต้องเลือก                    |
| --------------- | ------------------------------------------ | --------------------------- |
| ชนะผ่าน          | อีกฝั่งไม่มาแข่ง                              | ฝ่ายที่ชนะ                    |
| ปรับแพ้          | ฝั่งหนึ่งถูกปรับแพ้ (เช่น ผิดกติกา)              | ฝ่ายที่ชนะ                    |
| ไม่มีผล          | แมตช์ถูกยกเลิกกลางคัน ไม่นับผล                  | ไม่ต้องเลือก                  |
| แข่งจบตามปกติ     | ต้องแก้อันดับที่บันทึกไว้ผิด                       | อันดับของแต่ละฝ่าย              |

ผลพิเศษแทนผลจากคะแนน และตารางคะแนนคำนวณใหม่ตาม ฝั่งที่มาไม่ครบตอนรายงานตัว ปรับแพ้ได้จากหน้า
[รายงานตัวแข่งขัน](/docs/staff/tasks/match-checkin#ปรับแพ้ฝั่งที่มาไม่ครบ) ด้วย
