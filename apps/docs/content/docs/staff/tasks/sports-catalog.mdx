## กีฬา กับ ประเภท

- **กีฬา** เช่น ฟุตบอล แบดมินตัน Esports มีรูปหน้าปกและลำดับการแสดง
- **ประเภท** (ประเภทย่อย) เช่น “ฟุตบอลชาย” หรือ “แบดมินตันเดี่ยวหญิง” นักกีฬาสมัครที่ระดับประเภท

## เพิ่มกีฬา

<Steps>
<Step>

### กด “เพิ่มกีฬา”

</Step>
<Step>

### กรอกข้อมูล

**ชื่อ** **รหัส** (ตัวพิมพ์เล็ก a-z, 0-9 และ - เช่น `football`) **คำอธิบาย** **ภาพประกอบ** หรือ **รูปหน้าปก**
(เว้นว่างไว้เพื่อใช้ภาพประกอบที่เลือก) และ **ลำดับการแสดง**

</Step>
<Step>

### เพิ่มประเภท

ตั้งชื่อ เลือก **เพศ** (ชาย หญิง ผสม ไม่จำกัดเพศ) **รูปแบบ** (เดี่ยว คู่ ทีม) และ **จำนวนสูงสุดต่อสถาบัน**
(นับเฉพาะคนที่อนุมัติแล้ว เว้นว่างถ้าไม่จำกัด) แล้วติ๊กข้อมูลที่นักกีฬาต้องกรอกเพิ่ม

</Step>
<Step>

### เปิดรับสมัคร

สลับเป็น **เปิดรับสมัคร** เมื่อพร้อม นักกีฬาจะเห็นประเภทนี้ในหน้าสมัครกีฬา

</Step>
</Steps>

## ข้อมูลที่นักกีฬาต้องกรอกเพิ่ม

ทุกประเภทต้องกรอกรหัสนักศึกษา และติ๊กเพิ่มได้ตามกีฬา

| ตัวเลือก                                 | ใช้กับ                                |
| ---------------------------------------- | ------------------------------------- |
| ต้องกรอกเบอร์เสื้อ                       | กีฬาประเภททีม                         |
| ต้องเลือกมือ 1 หรือ มือ 2                | แบดมินตันเดี่ยว (สถาบันละ 1 คนต่อมือ) |
| ต้องกรอก IGN, Facebook และเชื่อม Discord | Esports                               |

## กติกา

กด **กติกา** ที่การ์ดกีฬาเพื่อเปิดหน้ากติกาของกีฬานั้น กติกาที่บันทึกจะแสดงในแท็บกติกาของหน้าแมตช์ด้วย
ประเภทที่ไม่มีกติกาของตัวเองจะใช้กติกาของกีฬา

<Screenshot src="tech-head/sport-rules" alt="หน้าแก้กติกาแบบจัดรูปแบบ มีแถบเครื่องมือด้านบน" />

- **แก้ไข** เปิดตัวแก้แบบจัดรูปแบบ มีแถบเครื่องมือสำหรับชื่อกีฬา หัวข้อ หัวข้อย่อย ตัวหนา ตัวเอียง ลิงก์
  รายการ และข้อความอ้างอิง พิมพ์และเห็นหน้าตาจริงไปพร้อมกัน
- **แก้แบบ Markdown** สลับไปแก้เป็นข้อความ Markdown พร้อมตัวอย่างข้างกัน สำหรับคนที่ถนัดแบบนี้
  สลับไปมาได้โดยเนื้อหาไม่หาย
- **อัปโหลด .md** หรือลากไฟล์มาวางในช่องแก้ จะแทนเนื้อหาทั้งหมดด้วยไฟล์นั้น ตรวจดูแล้วค่อยกดบันทึก
- **ดาวน์โหลด .md** เก็บกติกาเป็นไฟล์ไว้ได้ทุกเมื่อ
- กติกายาวได้ไม่เกิน 30,000 ตัวอักษร ถ้าออกจากหน้าโดยยังไม่บันทึก ระบบจะถามก่อนทุกครั้ง
- ถ้ามีคนอื่นบันทึกกติกาเดียวกันไปก่อน ระบบจะไม่ทับของเขา ให้ดาวน์โหลดของคุณเก็บไว้ แล้วโหลดหน้าใหม่

## ลบ

- ลบ **ประเภท** ได้เมื่อยังไม่มีผู้สมัครหรือกิจกรรมในประเภทนั้น
- ลบ **กีฬา** ได้เมื่อไม่มีประเภทย่อยเหลืออยู่
- ถ้าลบไม่ได้แต่ไม่อยากให้สมัครเพิ่ม ให้ **ปิดรับสมัคร** แทน
