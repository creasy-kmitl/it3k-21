## ส่งอีเมล

<Steps>
<Step>

### เขียน “หัวเรื่อง” และ “เนื้อหา”

เช่น “แจ้งกำหนดการรายงานตัวนักกีฬา” ใส่รูป ลิงก์ และหัวข้อได้ในตัวแก้ไข

</Step>
<Step>

### เลือกผู้รับ

| วิธี           | ตัวเลือก                                                                    |
| -------------- | --------------------------------------------------------------------------- |
| กลุ่มผู้รับ     | ทุกคนที่ส่งข้อมูลลงทะเบียนแล้ว · นักกีฬา (กรองตามกีฬา ประเภท สถาบัน สถานะการสมัคร) · ผู้ถือตั๋วของกิจกรรม |
| ผู้ใช้ในระบบ    | ค้นหาชื่อหรืออีเมล แล้วกด **เพิ่ม** ทีละคน                                     |
| อีเมลอื่น      | พิมพ์อีเมล คั่นแต่ละอีเมลด้วยจุลภาคหรือขึ้นบรรทัดใหม่                              |

รวมแล้วส่งได้ครั้งละไม่เกิน **2,000 คน**

</Step>
<Step>

### ดู “ตัวอย่างอีเมล”

ตรวจหน้าตา หัวเรื่อง และจำนวนผู้รับ

</Step>
<Step>

### กด “ส่งอีเมล”

</Step>
</Steps>

<Callout type="warn" title="ส่งแล้วยกเลิกไม่ได้">
  อีเมลถูกเข้าคิวส่งทันที ตรวจตัวอย่างและจำนวนผู้รับให้ดีก่อนกดส่ง
</Callout>

## ประวัติการส่ง

ส่วน **ประวัติการส่ง** แสดงหัวเรื่อง ผู้ส่ง เวลา และจำนวนที่ส่งแล้ว ใช้ตรวจว่ามีคนส่งเรื่องเดียวกันไปแล้วหรือยัง
