<PageHero spot="whistle">
  ก่อนแมตช์เริ่ม นักกีฬาต้องรายงานตัว การรายงานตัวอยู่ในหน้าของแต่ละแมตช์ (**แมตช์** → กดแมตช์ → ส่วน **รายงานตัว**)
  ใช้เปิด kiosk ให้นักกีฬาสแกนเอง ติ๊กชื่อแทนนักกีฬา และปรับแพ้ฝั่งที่มาไม่ครบหลังปิดรายงานตัว
</PageHero>

<Callout title="คนละเรื่องกับเช็คอินกิจกรรม">
  หน้านี้รายงานตัวเข้า **แมตช์** ด้วย **รหัสเช็คอินกีฬา** 6 หลักในหน้าโปรไฟล์ของนักกีฬา ส่วนการเช็คอินเข้า **กิจกรรม** ด้วย QR ตั๋ว
  อยู่ที่ [เช็คอินหน้างาน](/docs/staff/tasks/check-in)
</Callout>

## ใครใช้ได้

ส่วน **รายงานตัว** ในหน้าแมตช์มีสำหรับ Tech/Live, ทะเบียน สจล., หัวหน้า/รองหัวหน้าฝ่ายกีฬา และ Admin
สตาฟฝ่ายกีฬาเปิดหน้าแมตช์ได้ แต่จะไม่เห็นส่วนนี้ ไม่มีเมนูรายงานตัวแยกแล้ว

## เวลารายงานตัว

แต่ละประเภทกำหนดเวลาเปิดและปิดรายงานตัวไว้ใน [ตั้งค่าการแข่งของประเภท](/docs/staff/tasks/competition-settings#รายงานตัว)
ค่าตั้งต้นคือเปิด 40 นาทีและปิด 10 นาทีก่อนเวลาแข่ง

| ช่วงเวลา              | ข้อความในส่วนรายงานตัว          | นักกีฬาสแกนที่ kiosk | สตาฟติ๊กเอง | ปรับแพ้ |
| --------------------- | ---------------------------- | :---------------: | :--------: | :-----: |
| ก่อนเปิด               | เปิดรายงานตัว 12:20           |                   |     ✓      |         |
| ระหว่างเปิด            | เปิดรายงานตัว ถึง 12:50        |         ✓         |     ✓      |         |
| ปิดแล้ว จนถึงเริ่มแข่ง    | ปิดรายงานตัวแล้ว               |                   |     ✓      |    ✓    |
| เริ่มแข่ง จบ หรือยกเลิก   | แมตช์นี้เริ่มแข่ง จบ หรือยกเลิกแล้ว |                   |            |         |

แมตช์ที่ยังไม่กำหนดเวลาไม่มีช่วงรายงานตัว สแกนที่ kiosk ไม่ได้ แต่สตาฟติ๊กเองได้

## ส่วนรายงานตัวในหน้าแมตช์

- ไปที่ **แมตช์** แล้วกดแมตช์ที่จะเช็คอิน ส่วน **รายงานตัว** อยู่ใต้ **ผู้แข่ง**
- บรรทัดบนสุดบอกช่วงรายงานตัวและจำนวนขั้นต่ำต่อฝั่ง
- แต่ละฝั่งมีจำนวนที่รายงานตัวแล้วเทียบกับขั้นต่ำ และรายชื่อนักกีฬาให้ติ๊ก
- แมตช์ย่อย (เช่น คู่ในแบดมินตันทีม) ไม่มีส่วนนี้ นักกีฬารายงานตัวกับแมตช์หลัก

## เปิด kiosk ของแมตช์

<Steps>
<Step>

### กด “เปิด kiosk” ในส่วนรายงานตัว

ปุ่มนี้มีเฉพาะประเภทที่ตั้งเป็น **สแกนที่สนาม** และแมตช์ที่ยังไม่เริ่ม kiosk หนึ่งหน้าใช้กับแมตช์เดียว
ถ้าสนามเดียวกันมีหลายแมตช์ต่อกัน ให้กด **ออก** แล้วเปิด kiosk ของแมตช์ถัดไป

</Step>
<Step>

### ตั้ง kiosk บนแท็บเล็ตหรือคอมพิวเตอร์ที่สนาม

หน้า kiosk ใช้กล้องของเครื่อง (ต้องกดอนุญาตกล้อง) หรือเครื่องสแกนบาร์โค้ดที่ต่อไว้ ถ้าเปิดกล้องไม่ได้
ก็พิมพ์รหัส 6 หลักในช่อง **รหัสเช็คอินกีฬา** แล้วกด Enter ได้ จอแสดงการ์ดแมตช์ และรายชื่อของแต่ละฝั่งว่าใครรายงานตัวแล้ว

</Step>
<Step>

### ให้นักกีฬาหันบาร์โค้ดเข้ากล้อง

นักกีฬาเปิดการ์ด **รหัสเช็คอินกีฬา** ในหน้าโปรไฟล์ของตัวเอง (ไม่ใช่ QR ตั๋วกิจกรรม) บาร์โค้ดสั้น สแกนติดง่าย
บาร์โค้ดรหัสผู้ใช้ในการ์ดรูปโปรไฟล์ก็ใช้ได้เหมือนกัน ดูผลบนจอ แล้วกด **แตะเพื่อสแกนคนถัดไป**

</Step>
</Steps>

<Screenshot src="tech-head/match-kiosk" alt="kiosk รายงานตัวของแมตช์ กล้องอยู่ซ้าย การ์ดแมตช์และรายชื่อของแต่ละฝั่งอยู่ขวา" />

กด **ออก** เพื่อกลับไปหน้าแมตช์

### ผลการสแกน

| ข้อความบนจอ                                        | หมายความว่า                                                    |
| ------------------------------------------------- | ------------------------------------------------------------- |
| รายงานตัวสำเร็จ · มจธ. รายงานตัวแล้ว 3 / 5 คน           | สำเร็จ พร้อมจำนวนของฝั่งนั้น                                       |
| รายงานตัวไปแล้วเมื่อ 12:31                            | สแกนซ้ำ ไม่นับเพิ่ม                                               |
| ยังไม่เปิดรายงานตัว (เปิด 12:20)                       | มาเร็วเกินไป ให้รอถึงเวลาเปิด                                       |
| ปิดรายงานตัวแล้ว ติดต่อเจ้าหน้าที่สนาม                    | มาหลังปิด สตาฟติ๊กให้ในหน้าแมตช์ได้ ถ้าแมตช์ยังไม่เริ่ม                 |
| ไม่อยู่ในรายชื่อผู้เล่นของแมตช์นี้ ติดต่อผู้จัดการทีม          | แมตช์นี้มีรายชื่อลงแข่ง แต่นักกีฬาคนนี้ไม่อยู่ในรายชื่อ                    |
| นักกีฬาคนนี้ไม่ได้อยู่ในทีมของแมตช์นี้                     | นักกีฬาไม่ได้แข่งแมตช์นี้ อาจเปิด kiosk ผิดแมตช์หรือนักกีฬามาผิดคิว       |
| แมตช์นี้เริ่มแข่ง จบ หรือยกเลิกแล้ว เช็คอินไม่ได้           | แมตช์ไม่รับรายงานตัวแล้ว                                           |
| ประเภทนี้รายงานตัวกับเจ้าหน้าที่ ไม่ใช้ kiosk               | ประเภทนี้ตั้งเป็น **เจ้าหน้าที่ติ๊ก** ให้ติ๊กในหน้าแมตช์แทน               |
| นี่คือ QR ตั๋วกิจกรรม ใช้รหัสเช็คอินกีฬา…                 | สแกน QR ตั๋วผิดอัน ให้เปิดรหัสเช็คอินกีฬาในหน้าโปรไฟล์แทน                |
| ไม่พบนักกีฬาของรหัสนี้                                 | รหัสไม่ใช่ของระบบนี้ หรือพิมพ์ผิด                                     |

ถ้าแมตช์นั้นมี [รายชื่อลงแข่ง](/docs/staff/tasks/competition#รายชื่อลงแข่ง) นักกีฬาต้องอยู่ในรายชื่อ ถ้ายังไม่มีรายชื่อ ทุกคนในทีมรายงานตัวได้

## ติ๊กรายงานตัวเอง

ในส่วน **รายงานตัว** ของหน้าแมตช์ ติ๊กหน้าชื่อเพื่อรายงานตัวแทนนักกีฬา เอาติ๊กออกเพื่อยกเลิก
(เช่น สแกนผิดคน) แล้วนักกีฬาคนนั้นสแกนใหม่ได้

- ใต้ชื่อบอกเวลาและวิธี: **สแกน** หรือ **เจ้าหน้าที่** พร้อมชื่อสตาฟที่ติ๊ก
- ป้าย **ตัวจริง** / **ตัวสำรอง** มาจากรายชื่อลงแข่ง ป้าย **ไม่อยู่ในรายชื่อแล้ว** คือคนที่รายงานตัวไว้แล้วถูกเอาออกจากรายชื่อทีหลัง
- ติ๊กได้ทุกเวลาก่อนแมตช์เริ่ม แม้ยังไม่เปิดหรือปิดรายงานตัวไปแล้ว
- Esports ที่ตั้งเป็น **เจ้าหน้าที่ติ๊ก** มีข้อความ "ประเภทนี้รายงานตัวผ่าน Discord" ให้ติ๊กชื่อคนที่รายงานตัวใน Discord แล้ว

## ปรับแพ้ฝั่งที่มาไม่ครบ

หลังปิดรายงานตัวและก่อนแมตช์เริ่ม ถ้ามีฝั่งที่รายงานตัวไม่ถึง **ต้องมาอย่างน้อย** ส่วนรายงานตัวของแมตช์จะมีกล่องสีแดง
"ปิดรายงานตัวแล้ว … ยังมีผู้เล่นไม่ครบ"

<Steps>
<Step>

### กด “ปรับแพ้ (ชื่อฝั่ง)”

ถ้าไม่ครบทั้งสองฝั่ง จะมีปุ่ม **ปรับแพ้ทุกฝั่งที่ไม่ครบ** ด้วย

</Step>
<Step>

### อ่านผลแล้วกด “ยืนยันปรับแพ้”

หน้าต่างยืนยันบอกจำนวนที่มาเทียบกับขั้นต่ำ และผลที่จะเกิด

- ปรับแพ้ฝั่งเดียวในแมตช์สองฝั่ง: อีกฝั่ง **ชนะผ่าน** และแมตช์จบทันที
- ปรับแพ้ทุกฝั่ง: ไม่มีผู้ชนะ และแมตช์จบทันที
- แมตช์ที่มีมากกว่าสองฝั่ง: ฝั่งที่เหลือแข่งต่อตามปกติ

</Step>
</Steps>

ปรับแพ้แล้วย้อนกลับจากหน้านี้ไม่ได้ ถ้าต้องแก้ ให้ใช้ **ผลพิเศษ** ในหน้า [ใส่คะแนน](/docs/staff/tasks/scoring#ผลพิเศษ)
ผลปรับแพ้นับในตารางคะแนนตามแต้ม **ปรับแพ้** ที่ประเภทนั้นตั้งไว้
