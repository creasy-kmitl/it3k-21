รายการแสดง **เฉพาะที่ยังไม่จบ** เป็นค่าเริ่มต้น กด **แสดงที่จบแล้ว** เพื่อดูย้อนหลัง แต่ละการ์ดบอกจำนวนตั๋ว เช่น “ตั๋ว 12/50 · เปิดรับ”

## สร้างกิจกรรม

<Steps>
<Step>

### กด “เพิ่มกิจกรรม”

ตั้ง **ชื่อกิจกรรม** และลิงก์ก่อน แล้วกด **สร้างแล้วแก้ไขต่อ**

</Step>
<Step>

### กรอก “ข้อมูลกิจกรรม”

- **ประเภทกิจกรรม** กิจกรรมทั่วไป หรือการแข่งขันกีฬา
- **ลิงก์กิจกรรม (slug)** สร้างจากตัวอักษรอังกฤษในชื่อให้ แก้เองได้ (a-z, 0-9 และขีดกลาง)
  ลิงก์นี้ใช้ทั้งหน้ากิจกรรม `/events/<slug>` และ Kiosk `/kiosk/<slug>`
- **รูปปก** ไม่ใส่ก็ได้ ระบบจะใช้ภาพประกอบแทน

</Step>
<Step>

### ตั้ง “เวลาและสถานที่”

**เริ่ม** และ **สิ้นสุด** เป็นเวลาไทย (UTC+07:00) เลือก **สถานที่** จากรายการ ถ้าไม่มี ให้เพิ่มที่หน้า [สถานที่](/docs/staff/tasks/venues) ก่อน

</Step>
<Step>

### เขียน “เนื้อหา”

แสดงในหน้ากิจกรรมของผู้เข้าร่วม ส่วนต้นของเนื้อหาจะเป็นคำอธิบายบนการ์ดและพรีวิวลิงก์ วางหรือลากรูปมาใส่ได้
(รูปเก็บในคลังไฟล์ของคุณ ถ้าลบไฟล์ทีหลัง รูปในหน้ากิจกรรมจะหายด้วย)

</Step>
<Step>

### ตั้ง “ตั๋ว” แล้วกด “บันทึกการแก้ไข”

ดูหัวข้อถัดไป

</Step>
</Steps>

## ตั๋ว

ต้องมีตั๋วจึงจะเช็คอินได้ ตั๋วแต่ละใบเช็คอินได้ครั้งเดียว และปิดรับเองเมื่อกิจกรรมจบ

- **เปิดรับตั๋ว** สวิตช์หลักของทั้งกิจกรรม ปิดไว้ระหว่างเตรียมงาน ผู้เข้าร่วมจะยังไม่เห็นในรายการกิจกรรม
- **จำนวนตั๋วรวมสูงสุด** รวมทุกประเภท เว้นว่างถ้าไม่จำกัด
- **ประเภทตั๋ว** กด “เพิ่มประเภทตั๋ว” แล้วตั้ง ชื่อ (เช่น ผู้ชมทั่วไป, VIP, นักกีฬา) คำอธิบาย จำนวนตั๋ว และ **สูงสุดต่อคน**

### ใครรับตั๋วได้

| ตัวเลือก             | ความหมาย                                                      |
| ------------------- | ------------------------------------------------------------- |
| ทุกคน               | ผู้เข้าร่วมทุกคน                                                 |
| บทบาท               | เฉพาะบทบาทที่เลือก เช่น Staff/Admin สำหรับตั๋วทีมงาน               |
| สถาบัน              | เฉพาะบัญชีของสถาบันที่เลือก                                       |
| นักกีฬาของกีฬา       | ผู้ที่สมัครกีฬานั้นและได้รับอนุมัติแล้ว                             |
| นักกีฬาในรายชื่อ     | เฉพาะนักกีฬาในรายชื่อกิจกรรมนี้ (ใช้ได้เฉพาะกิจกรรมกีฬา)            |

ปิดประเภทตั๋วไว้ก่อนได้ ตั๋วที่รับไปแล้วยังใช้เช็คอินได้ ประเภทที่มีคนรับแล้วลบไม่ได้

## กิจกรรมกีฬาและรายชื่อผู้เข้าร่วม

ถ้าเลือกประเภทกิจกรรมเป็นกีฬา จะมีช่อง **ประเภทกีฬา** และ **สถาบันที่เข้าร่วม**
นักกีฬาที่อนุมัติแล้วในประเภทกีฬาและสถาบันเหล่านี้คือรายชื่อของกิจกรรม

แท็บ **ผู้เข้าร่วม** (`⌘1`) แสดงรายชื่อพร้อมสถานะ “ยังไม่รับตั๋ว” “ยังไม่เช็คอิน” “เช็คอินแล้ว”
ส่วนแท็บ **แก้ไข** (`⌘2`) คือฟอร์มด้านบน

## ลบกิจกรรม

ส่วน **ลบกิจกรรม** ท้ายหน้าแก้ไข ลบกิจกรรมพร้อมตั๋วและการเช็คอินทั้งหมด **ย้อนกลับไม่ได้**
ถ้าแค่เลื่อนหรือไม่อยากให้รับตั๋วเพิ่ม ให้แก้เวลาหรือปิด “เปิดรับตั๋ว” แทน
