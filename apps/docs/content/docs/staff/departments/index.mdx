<PageHero spot="flag">
  เลือกฝ่ายของคุณจากตารางด้านล่าง แล้วเปิดหน้าตามตำแหน่ง (สตาฟ หรือหัวหน้า/รองหัวหน้า) มีเพียง
  **Tech/Live** และ **ทะเบียน** ที่มีคู่มือแยก เพราะได้สิทธิ์พิเศษ อีก 14 ฝ่ายใช้คู่มือ “ฝ่ายอื่น ๆ”
  ร่วมกัน โดยฝ่าย **กีฬา** ได้สิทธิ์ระบบแข่งขันเพิ่ม (ทีมแข่ง แมตช์ และคะแนน)
</PageHero>

| ----------- | -------------- | ----------- | ------------------------------------------------------------------------------------------------- |
| Tech/Live   | `tech-live`    | ✓ (สงวนไว้) | [ฝ่าย Tech/Live](/docs/staff/departments/tech-live)                                               |
| ทะเบียน     | `registration` | ✓ (สงวนไว้) | [ฝ่ายทะเบียน](/docs/staff/departments/registration)                                               |
| สวัสดิการ   | `welfare`      |             | [ฝ่ายอื่น ๆ](/docs/staff/departments/others)                                                      |
| สถานที่     | `venue`        |             | ฝ่ายอื่น ๆ                                                                                        |
| พิธีการ     | `ceremony`     |             | ฝ่ายอื่น ๆ                                                                                        |
| พาเหรด      | `parade`       |             | ฝ่ายอื่น ๆ                                                                                        |
| พัสดุ       | `supplies`     |             | ฝ่ายอื่น ๆ                                                                                        |

<Callout title="ฝ่ายกีฬาดูแลการแข่งขัน ไม่ได้ดูแลการสมัคร">
  ฝ่ายกีฬาจัดทีมแข่ง ตารางแข่ง และใส่คะแนน ส่วนประเภทกีฬา กิจกรรม สถานที่ การสมัครนักกีฬา และ Kiosk
  เช็คอินกิจกรรม ยังดูแลโดยฝ่าย **Tech/Live** และ **ทะเบียน** ถ้าต้องแก้ส่วนนั้น
  ให้ประสานหัวหน้าฝ่าย Tech/Live หรือทะเบียน
</Callout>

## สิทธิ์พิเศษของสามฝ่าย

| สิทธิ์                                      | Tech/Live |         ทะเบียน         |          กีฬา           |
| ------------------------------------------- | :-------: | :---------------------: | :---------------------: |
| เปิดหน้า “ผู้ใช้” และดูแลบัญชี              |     ✓     |            ✓            |                         |
| แก้ไขลิงก์สั้นของทุกคน และ Preset QR ทุกอัน |     ✓     |                         |                         |
| ระบบกีฬาและ Kiosk เช็คอิน                   |     ✓     |            ✓            |                         |
| ตรวจใบสมัครนักกีฬา                          |  หัวหน้า  |         หัวหน้า         |                         |
| แก้กติกาของกีฬา                             |     ✓     |          สจล.           | หัวหน้า/รองหัวหน้า สจล. |
| ดูทีมแข่งและแมตช์ ใส่คะแนน                  |     ✓     |          สจล.           |          สจล.           |
| จัดทีม ตารางแข่ง และตั้งค่าการแข่งของประเภท |     ✓     | หัวหน้า/รองหัวหน้า สจล. | หัวหน้า/รองหัวหน้า สจล. |
| เช็คอินนักกีฬาก่อนแมตช์                     |     ✓     |          สจล.           | หัวหน้า/รองหัวหน้า สจล. |
| ส่งอีเมลถึงผู้เข้าร่วม                      |   ทุกคน   | หัวหน้า/รองหัวหน้า สจล. |                         |
| เพิ่มและแก้ไขรายชื่อฝ่าย                    |           | หัวหน้า/รองหัวหน้า สจล. |                         |
