<PageHero spot="crown">
  หัวหน้าและรองหัวหน้าฝ่าย Tech/Live ของ สจล. มี **สิทธิ์เต็ม** เกือบเท่า Admin ให้สถานะได้ทุกแบบยกเว้น Admin
  จัดการที่นั่งหัวหน้าทุกฝ่าย และดูแลระบบกีฬาทั้งหมด
</PageHero>

## เมนูที่คุณจะเห็น

<SidebarShot src="tech-head/sidebar" alt="เมนูของหัวหน้าฝ่าย Tech/Live">

เหมือนสตาฟ Tech/Live แต่ทุกหน้าในกลุ่ม **กีฬา** แก้ไขได้ (ไม่มีเมนู “ฝ่าย” ซึ่งเป็นของหัวหน้าฝ่ายทะเบียนและ Admin)

</SidebarShot>

## คุณทำอะไรได้บ้าง

ทุกอย่างที่ [สตาฟ Tech/Live](/docs/staff/departments/tech-live/staff) ทำได้ และเพิ่มอีก

| งาน                                                           | ขั้นตอน                                                  |
| ------------------------------------------------------------- | -------------------------------------------------------- |
| ให้สถานะ Guest ผู้เข้าร่วม นักกีฬา Staff หัวหน้า รองหัวหน้า       | [จัดการผู้ใช้](/docs/staff/tasks/users)                     |
| เชิญคนนอกมหาวิทยาลัยเป็นสถานะใดก็ได้                             | [เชิญผู้ใช้](/docs/staff/tasks/invitations)                  |
| เพิ่ม ลบ ย้ายที่นั่งหัวหน้าฝ่ายทุกฝ่าย                             | [จัดการที่นั่งหัวหน้าฝ่าย](/docs/staff/tasks/leadership)       |
| ปรับโควตาพื้นที่จัดเก็บ                                          | [จัดการผู้ใช้](/docs/staff/tasks/users#โควตาพื้นที่จัดเก็บ)     |
| อนุมัติ ไม่อนุมัติ แก้ไข และส่งออกใบสมัครนักกีฬา                   | [ตรวจใบสมัครนักกีฬา](/docs/staff/tasks/athletes)             |
| สร้างและแก้ประเภทกีฬา                                           | [ประเภทกีฬา](/docs/staff/tasks/sports-catalog)               |
| สร้างกิจกรรม ประเภทตั๋ว และรายชื่อผู้เข้าร่วม                       | [กิจกรรมและตั๋ว](/docs/staff/tasks/events)                  |
| บังคับเช็คอิน และยกเลิกการเช็คอิน                                 | [เช็คอินหน้างาน](/docs/staff/tasks/check-in)                 |
| เพิ่มสถานที่บนแผนที่                                             | [สถานที่](/docs/staff/tasks/venues)                         |

<Callout type="warn" title="สิ่งที่ยังต้องให้ Admin ทำ">
  ให้หรือถอนสถานะ Admin แก้บัญชีของ Admin และแก้รายชื่อฝ่าย (หน้า “ฝ่าย” เป็นของ Admin และหัวหน้าฝ่ายทะเบียน)
</Callout>
