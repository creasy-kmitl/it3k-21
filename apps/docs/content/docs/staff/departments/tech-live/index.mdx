  ฝ่าย **Tech/Live** ดูแลระบบนี้ทั้งระบบ ทั้งบัญชีผู้ใช้ ลิงก์สั้น ระบบกีฬา การเช็คอินหน้างาน และการส่งอีเมลถึงผู้เข้าร่วม
  สิทธิ์ผูกกับรหัสฝ่าย `tech-live`
</PageHero>

## สตาฟกับหัวหน้าต่างกันอย่างไร

| งาน                                         | สตาฟ                          | หัวหน้า / รองหัวหน้า (สจล.)      |
| ------------------------------------------- | ----------------------------- | ------------------------------- |
| ใช้เครื่องมือพื้นฐาน (ปฏิทิน QR ลิงก์สั้น)    | ✓                             | ✓                               |
| แก้ไขลิงก์สั้นและ Preset QR ของทุกคน         | ✓                             | ✓                               |
| หน้า “ผู้ใช้”                                | ให้สถานะ Guest กับบัญชีที่ยังไม่ใช่ทีมงาน | ให้ทุกสถานะ ยกเว้น Admin          |
| เชิญผู้ใช้                                   | เชิญเป็น Guest                 | เชิญเป็นสถานะใดก็ได้              |
| จัดการที่นั่งหัวหน้าฝ่าย                       |                               | ✓                               |
| โควตาพื้นที่จัดเก็บ                           |                               | ✓                               |
| ดูรายชื่อนักกีฬา                              | ✓ (ทุกสถาบัน)                  | ✓                               |
| ตรวจ แก้ไข ส่งออกใบสมัครนักกีฬา                |                               | ✓                               |
| กิจกรรม ประเภทกีฬา สถานที่                    | ดูอย่างเดียว                   | สร้าง แก้ไข ลบ                   |
| สแกนเช็คอิน / Kiosk                          | ✓                             | ✓                               |
| บังคับเช็คอิน (ไม่มีตั๋ว)                      |                               | ✓                               |
| ทีมแข่ง แมตช์ รายงานตัวแข่งขัน ใส่คะแนน          | ✓                             | ✓                               |
| ส่งอีเมล                                     | ✓                             | ✓                               |
