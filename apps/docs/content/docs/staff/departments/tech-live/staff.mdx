## เมนูที่คุณจะเห็น

<SidebarShot src="tech-staff/sidebar" alt="เมนูของสตาฟฝ่าย Tech/Live">

นอกจาก [เครื่องมือพื้นฐาน](/docs/staff/basics/sidebar) คุณจะเห็น **ผู้ใช้** **กิจกรรม** **ประเภทกีฬา** **นักกีฬา**
**สถานที่** และ **ส่งอีเมล**

</SidebarShot>

## คุณทำอะไรได้บ้าง

| ทำได้                                                   | ทำไม่ได้ (ติดต่อหัวหน้าฝ่าย)                          |
| ------------------------------------------------------- | ---------------------------------------------------- |
| ค้นหาบัญชีและดูสถานะ ฝ่าย สถาบันของทุกคน                 | ให้สถานะผู้เข้าร่วม นักกีฬา Staff หรือที่นั่ง           |
| ทำให้บัญชีที่ยังไม่ใช่ทีมงานเป็น Guest                   | แก้บัญชีที่เป็นทีมงานแล้ว หรือผู้ที่มีที่นั่ง            |
| เชิญผู้ใช้เป็น Guest                                     | ปรับโควตาพื้นที่จัดเก็บ                                |
| แก้ไขลิงก์สั้นและ Preset QR ของทุกคน                     | สร้างหรือแก้กิจกรรม ประเภทกีฬา สถานที่                 |
| ดูรายชื่อนักกีฬาทุกสถาบัน                                 | อนุมัติหรือแก้ไขใบสมัครนักกีฬา                          |
| สแกนเช็คอินและเปิด Kiosk                                 | บังคับเช็คอินคนที่ไม่มีตั๋ว                             |
| ส่งอีเมลถึงผู้เข้าร่วม นักกีฬา และผู้ถือตั๋ว                |                                                      |

## งานหลัก

### ช่วยดูบัญชีผู้ใช้

<Screenshot src="tech-staff/users" alt="หน้าผู้ใช้ของสตาฟ Tech/Live" />

ค้นหาชื่อ แล้วดูว่าบัญชีอยู่สถานะอะไร สังกัดฝ่ายไหน ถ้าคนแจ้งว่าเข้าระบบทีมงานไม่ได้ ส่วนใหญ่เพราะยังเป็น Guest
หรือยังไม่มีฝ่าย ให้ส่งต่อหัวหน้าฝ่ายเพื่อให้สถานะ Staff ดูขั้นตอนเต็มที่ [จัดการผู้ใช้](/docs/staff/tasks/users)

<Screenshot src="tech-staff/user-edit" alt="หน้าต่างแก้ไขผู้ใช้ เลือกได้เฉพาะ Guest" />

### ยืนจุดเช็คอิน

<Steps>
<Step>

### เปิดกิจกรรม

ไปที่ **กิจกรรม** แล้วเลือกกิจกรรมที่จะเช็คอิน

</Step>
<Step>

### กด “สแกนเช็คอิน” หรือเปิด Kiosk

สแกนในหน้าเว็บด้วยกล้องมือถือ หรือเปิด **Kiosk เช็คอิน** บนแท็บเล็ต/คอมพิวเตอร์ที่ต่อเครื่องสแกน

</Step>
<Step>

### สแกน QR ตั๋ว หรือบาร์โค้ดผู้ใช้

ดูผลบนจอ แล้วสแกนคนถัดไป

</Step>
</Steps>

<Screenshot src="tech-staff/scan" alt="หน้าต่างสแกนเช็คอิน" />

ขั้นตอนเต็มและข้อความผิดพลาดแต่ละแบบอยู่ที่ [เช็คอินหน้างาน](/docs/staff/tasks/check-in)

### ส่งอีเมล

<Screenshot src="tech-staff/email" alt="หน้าส่งอีเมล" />

ดูขั้นตอนที่ [ส่งอีเมล](/docs/staff/tasks/email)

### ดูรายชื่อนักกีฬา

<Screenshot src="tech-staff/athletes" alt="รายชื่อนักกีฬาที่สตาฟ Tech/Live เห็น" />

คุณดูรายชื่อได้ทุกสถาบันเพื่อช่วยตอบคำถามหน้างาน แต่การอนุมัติและแก้ไขเป็นงานของหัวหน้า
ดูที่ [ตรวจใบสมัครนักกีฬา](/docs/staff/tasks/athletes)
