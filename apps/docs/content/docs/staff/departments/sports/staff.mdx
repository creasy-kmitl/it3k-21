<PageHero spot="whistle">
  สตาฟฝ่ายกีฬาของ สจล. ยืนข้างสนามและใส่คะแนนด้วยมือถือ คุณเห็นทีมแข่ง แมตช์ และสายการแข่งทั้งหมด
  แต่การจัดทีม จัดตาราง และเช็คอินนักกีฬาเป็นงานของหัวหน้าและรองหัวหน้า
</PageHero>

## เมนูที่คุณจะเห็น

<SidebarShot src="sports-staff/sidebar" alt="เมนูของสตาฟฝ่ายกีฬา">

นอกจาก [เครื่องมือพื้นฐาน](/docs/staff/basics/sidebar) คุณจะเห็น **กิจกรรม** **ประเภทกีฬา** **ทีมแข่ง** **แมตช์** และ **สถานที่**

</SidebarShot>

## คุณทำอะไรได้บ้าง

| ทำได้                                                   | ทำไม่ได้ (ติดต่อหัวหน้าฝ่าย)                                     |
| ------------------------------------------------------- | ------------------------------------------------------------- |
| ดูทีมแข่ง รายชื่อ และเจ้าหน้าที่ทีม                          | สร้าง แก้ หรือลบทีม                                             |
| ดูแมตช์ สายการแข่ง และตั้งค่าการแข่งของประเภท                | สร้างหรือแก้แมตช์ รายชื่อลงแข่ง กรรมการ รูป                          |
| ใส่คะแนน จบแมตช์ และบันทึกผลพิเศษ                         | เช็คอินนักกีฬาหรือเปิด kiosk รายงานตัว                               |
| ดูกิจกรรม ประเภทกีฬา สถานที่ และอ่านกติกา                   | แก้กติกา                                                       |

## งานหลัก: ใส่คะแนน

<Steps>
<Step>

### หาแมตช์ที่ได้รับมอบหมาย

ไปที่ **แมตช์** แล้วกดแท็บ **รายการ** แมตช์แบ่งตามวัน กรองด้วย **กีฬา** **ประเภท** **สนาม** หรือ **สถานะ** แล้วกดแมตช์นั้น
หรือเปิดลิงก์หน้าใส่คะแนนที่หัวหน้าส่งให้ แล้วข้ามไปขั้นที่ 3 ได้เลย

<Screenshot src="sports-staff/matches-list" alt="หน้าแมตช์ แท็บรายการ แมตช์แบ่งตามวันพร้อมตัวกรองกีฬา ประเภท สนาม และสถานะ" />

</Step>
<Step>

### กด “บันทึกคะแนน”

หน้าแมตช์ของสตาฟมีปุ่ม **บันทึกคะแนน** ปุ่มเดียว ส่วนรายชื่อ กรรมการ และรูปดูได้อย่างเดียว

<Screenshot src="sports-staff/match-detail" alt="หน้าแมตช์ของสตาฟฝ่ายกีฬา มีปุ่มบันทึกคะแนน และรายชื่อลงแข่งที่ดูได้อย่างเดียว" />

</Step>
<Step>

### กด “เริ่มแข่ง” แล้วกดคะแนนตามเกม

หน้าใส่คะแนนออกแบบมาให้ใช้บนมือถือ ใช้แนวนอนจะเห็นสองฝั่งข้างกัน และหน้าจอไม่ดับระหว่างใช้
กดผิดให้กด **ยกเลิก** ใต้ฝั่งนั้น เน็ตหลุดก็กดต่อได้ ระบบส่งให้เมื่อกลับมาออนไลน์

<Screenshot mobile="sports-staff/scoring-mobile" alt="หน้าใส่คะแนนบนมือถือ แบดมินตัน เกมที่ 1 มีปุ่ม +1 ของแต่ละฝั่ง ปุ่มเริ่มแข่ง ผลพิเศษ และจบแมตช์" />

ปุ่มของแต่ละวิธีนับคะแนนอยู่ที่ [แต่ละวิธีนับคะแนน](/docs/staff/tasks/scoring#แต่ละวิธีนับคะแนน)
ตอนเน็ตหลุดดูที่ [ตอนเน็ตหลุด](/docs/staff/tasks/scoring#ตอนเน็ตหลุด)

</Step>
<Step>

### กด “จบแมตช์” เมื่อได้ผล

ได้ผลตามกติกาแล้วปุ่มจะเป็นสีเข้ม กดแล้วยืนยัน ผลขึ้นหน้าสาธารณะและตารางคะแนนทันที
แมตช์ที่ไม่ได้แข่งตามปกติ (อีกฝั่งไม่มา ถูกปรับแพ้ หรือยกเลิกกลางคัน) ใช้ปุ่ม [ผลพิเศษ](/docs/staff/tasks/scoring#ผลพิเศษ)

</Step>
</Steps>

นาฬิกาจับเวลา การระบุผู้ทำแต้ม และการกรอกเวลาหรือระยะ ดูที่ [ใส่คะแนน](/docs/staff/tasks/scoring)

## ดูตารางแข่งและสาย

หน้า **แมตช์** เปิดมาที่แท็บ **สายการแข่ง** ดูได้ว่าใครจะเจอใครในรอบถัดไป ส่วนแท็บ **รายการ** แบ่งแมตช์ตามวัน
ดูรายละเอียดที่ [แมตช์และสายการแข่ง](/docs/staff/tasks/competition)
