<PageHero spot="whistle">
  ฝ่าย **กีฬา** ดูแลการแข่งขันหน้างาน ตั้งแต่จัดทีม จัดตารางแข่ง เช็คอินนักกีฬาก่อนลงสนาม จนถึงใส่คะแนนสด
  สิทธิ์ผูกกับรหัสฝ่าย `sports` และใช้ได้เฉพาะบัญชีของ สจล.
</PageHero>

<Callout title="ฝ่ายกีฬาดูแลการแข่งขัน ไม่ได้ดูแลการสมัคร">
  ประเภทกีฬา กิจกรรม สถานที่ การสมัครนักกีฬา และ Kiosk เช็คอินกิจกรรม ยังดูแลโดยฝ่าย **Tech/Live** และ **ทะเบียน**
  ถ้าต้องแก้ส่วนนั้น เช่น เพิ่มประเภทกีฬาหรือแก้ใบสมัครนักกีฬา ให้ประสานหัวหน้าฝ่าย Tech/Live หรือทะเบียน
</Callout>

## สตาฟกับหัวหน้าต่างกันอย่างไร

| งาน                                                   | สตาฟ (สจล.)   | หัวหน้า / รองหัวหน้า (สจล.) |
| ----------------------------------------------------- | :-----------: | :-----------------------: |
| ใช้เครื่องมือพื้นฐาน (ปฏิทิน QR ลิงก์สั้น)                | ✓             | ✓                         |
| ดูกิจกรรม ประเภทกีฬา และสถานที่                         | ดูอย่างเดียว   | ดูอย่างเดียว                |
| ดูทีมแข่ง แมตช์ และสายการแข่ง                           | ✓             | ✓                         |
| ใส่คะแนน และบันทึกผลพิเศษ                              | ✓             | ✓                         |
| จัดทีม เจ้าหน้าที่ทีม และตั้งค่าการแข่งของประเภท           |               | ✓                         |
| สร้างแมตช์ สายการแข่ง รายชื่อลงแข่ง กรรมการ และรูปแมตช์     |               | ✓                         |
| รายงานตัวแข่งขัน (kiosk ของแมตช์ ติ๊กเอง ปรับแพ้)          |               | ✓                         |
| แก้กติกาของกีฬาและประเภท                               |               | ✓                         |
| ดูรายชื่อนักกีฬา หรือตรวจใบสมัคร                         |               |                           |

สตาฟฝ่ายกีฬาของสถาบันอื่นไม่ได้สิทธิ์ระบบแข่งขัน ใช้ระบบเหมือน [ฝ่ายอื่น ๆ](/docs/staff/departments/others)
ส่วนที่นั่งหัวหน้าและรองหัวหน้ามีได้เฉพาะบัญชีของ สจล.
