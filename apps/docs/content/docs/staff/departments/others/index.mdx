<PageHero spot="megaphone">
  13 ฝ่ายในหน้านี้ใช้ระบบเหมือนกันทุกอย่าง ใช้ปฏิทินวางแผนงาน ดูรายชื่อหัวหน้าฝ่ายเพื่อประสานงาน
  และสร้าง QR กับลิงก์สั้นสำหรับสื่อของฝ่าย
</PageHero>

## ฝ่ายที่ใช้คู่มือนี้

| ฝ่าย        | ฝ่าย       | ฝ่าย    |
| ----------- | ---------- | ------- |
| สวัสดิการ   | สถานที่    | พิธีการ |
| พาเหรด      | พัสดุ      | พยาบาล  |
| ประสานงาน   | การเงิน    | Sponsor |
| Production  | PR         | Merchandise |
| Art         |            |         |

ฝ่ายกีฬามีสิทธิ์เพิ่มในระบบแข่งขัน จึงมีคู่มือแยกที่ [ฝ่ายกีฬา](/docs/staff/departments/sports)

## สตาฟกับหัวหน้าต่างกันอย่างไร

| งาน                                                | สตาฟ            | หัวหน้า / รองหัวหน้า |
| -------------------------------------------------- | --------------- | -------------------- |
| ดูปฏิทินทุกฝ่าย และเพิ่ม/แก้รายการของฝ่ายตัวเอง    | ✓               | ✓                    |
| QR Code และลิงก์สั้น (แก้ได้เฉพาะที่ตัวเองสร้าง)   | ✓               | ✓                    |
| ดูรายชื่อหัวหน้าฝ่ายทุกฝ่าย                        | ✓               | ✓                    |
| เปิดดูช่องทางติดต่อหัวหน้าฝ่าย                     | เฉพาะฝ่ายตัวเอง | ทุกฝ่าย              |
| แก้ชื่อเล่น เบอร์โทร ช่องทางติดต่อของที่นั่งตัวเอง |                 | ✓                    |

หัวหน้าฝ่ายอื่น ๆ เห็นเมนูเหมือนสตาฟ ส่วนการให้สถานะ Staff กับสมาชิกใหม่ในฝ่าย ต้องขอให้ฝ่าย Tech/Live หรือทะเบียนทำให้
