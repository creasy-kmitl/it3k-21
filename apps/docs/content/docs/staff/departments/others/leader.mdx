<PageHero spot="crown">
  หัวหน้าและรองหัวหน้าของฝ่ายทั่วไปใช้เมนูเดียวกับสตาฟ แต่ได้สิทธิ์เพิ่มสองอย่าง คือ **เปิดดูช่องทางติดต่อหัวหน้าทุกฝ่าย**
  เพื่อประสานงาน และ **แก้ข้อมูลติดต่อของที่นั่งตัวเอง**
</PageHero>

## เมนูที่คุณจะเห็น

<SidebarShot src="art-head/sidebar" alt="เมนูของหัวหน้าฝ่าย Art">

ใต้ชื่อในเมนูบัญชีจะเขียนว่า “หัวหน้าฝ่าย · Art” หรือ “รองหัวหน้าฝ่าย · Art”

</SidebarShot>

## คุณทำอะไรได้บ้าง

ทุกอย่างที่ [สตาฟฝ่ายอื่น ๆ](/docs/staff/departments/others/staff) ทำได้ และเพิ่มอีก

| งาน                                       | หมายเหตุ                                                    |
| ----------------------------------------- | ----------------------------------------------------------- |
| เปิดดูช่องทางติดต่อหัวหน้าทุกฝ่าย             | ทุกครั้งที่เปิดดูจะถูกบันทึก                                    |
| แก้ชื่อเล่น เบอร์โทร และโซเชียลของตัวเอง       | แก้ได้เฉพาะที่นั่งของตัวเอง                                    |

<Callout type="warn" title="สิ่งที่หัวหน้าฝ่ายทั่วไปทำไม่ได้">
  ให้สถานะ Staff กับสมาชิกใหม่ ย้ายคนเข้าออกฝ่าย และตั้งรองหัวหน้า ให้ส่งรายชื่อให้หัวหน้าฝ่าย Tech/Live หรือทะเบียนทำให้
  ส่วนสตาฟ Tech/Live และทะเบียนให้ได้เพียงสถานะ Guest
</Callout>

## แก้ข้อมูลติดต่อของตัวเอง

<Screenshot src="art-head/head" alt="หน้าหัวหน้าฝ่าย กรองเฉพาะฝ่าย Art" />

<Steps>
<Step>

### เปิดหน้า “หัวหน้าฝ่าย”

พิมพ์ชื่อฝ่ายหรือชื่อตัวเองในช่องค้นหา

</Step>
<Step>

### กดปุ่มดินสอที่ชื่อของคุณ

</Step>
<Step>

### แก้ข้อมูลติดต่อ แล้วบันทึก

ใส่ **ชื่อเล่น** **เบอร์โทร** (ตัวเลข + - ( ) และเว้นวรรค) และช่องทางโซเชียล เช่น LINE หรือ Instagram
แต่ละแพลตฟอร์มใส่ได้ครั้งเดียว ลิงก์ต้องขึ้นต้นด้วย `https://` ข้อมูลเดิมทั้งหมดจะถูกแทนที่ด้วยข้อมูลที่บันทึกใหม่

</Step>
</Steps>

<Screenshot src="art-head/head-edit" alt="ฟอร์มแก้ข้อมูลติดต่อของหัวหน้าฝ่าย" />

<Callout title="ข้อมูลของคุณถูกปกป้อง">
  สตาฟฝ่ายอื่นเปิดดูเบอร์ของคุณไม่ได้ คนที่เห็นมีเพียงสตาฟฝ่ายของคุณ หัวหน้า/รองหัวหน้าทุกฝ่าย และ Admin
  และระบบเก็บประวัติว่าใครเปิดดูเมื่อไร
</Callout>
