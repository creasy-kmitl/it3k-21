## เมนูที่คุณจะเห็น

<SidebarShot src="art-staff/sidebar" alt="เมนูของสตาฟฝ่าย Art">

**หน้าหลัก** **ปฏิทิน** **หัวหน้าฝ่าย** **QR Code** และ **ลิงก์สั้น**

</SidebarShot>

## คุณทำอะไรได้บ้าง

| ทำได้                                                  | ทำไม่ได้                                           |
| ------------------------------------------------------ | ------------------------------------------------- |
| ดูกำหนดการของแผนกใน 7 วันข้างหน้า                        | แก้รายการปฏิทินของฝ่ายอื่น                          |
| เพิ่ม แก้ไข เลื่อน ยกเลิกรายการปฏิทินของฝ่ายตัวเอง          | แก้ลิงก์สั้นของคนอื่น (ติดต่อ Tech/Live)             |
| ชวนฝ่ายอื่นเป็นฝ่ายที่ทำงานร่วมกัน                         | ดูช่องทางติดต่อหัวหน้าฝ่ายอื่น                       |
| สร้าง QR และลิงก์สั้น และดูสถิติลิงก์ของตัวเอง             | เข้าหน้าผู้ใช้ กิจกรรม นักกีฬา หรือส่งอีเมล           |
| เปิดดูเบอร์โทรหัวหน้า/รองหัวหน้าฝ่ายตัวเอง                  |                                                   |

### ลงกำหนดการของฝ่าย

<Screenshot src="art-staff/calendar-new" alt="หน้าต่างเพิ่มรายการปฏิทินของฝ่าย Art" />

กด **เพิ่มรายการ** เลือกแผนกเป็นฝ่ายของคุณ ใส่เวลา แล้วเลือก **ฝ่ายที่ทำงานร่วมกัน** ถ้าต้องให้ฝ่ายอื่นเห็นด้วย
เช่น งานติดตั้งเวทีที่ต้องมีฝ่ายสถานที่และ Production ขั้นตอนเต็มอยู่ที่ [ปฏิทิน](/docs/staff/basics/calendar)

<Screenshot src="art-staff/links-create" alt="หน้าต่างสร้างลิงก์สั้น" />

</Callout>
