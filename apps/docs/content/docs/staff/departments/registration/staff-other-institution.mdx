<PageHero spot="medal">
  สตาฟทะเบียนของ **สถาบันอื่น** (เช่น มจธ. มจพ.) ดูแลนักกีฬาของสถาบันตัวเอง คุณเห็นและส่งออกรายชื่อได้
  **เฉพาะนักกีฬาที่สมัครในนามสถาบันของบัญชีคุณ** เท่านั้น
</PageHero>

## เมนูที่คุณจะเห็น

<Screenshot src="reg-other/sidebar" alt="เมนูของสตาฟทะเบียน มจธ." />

## คุณทำอะไรได้บ้าง

| ทำได้                                          | ทำไม่ได้                                            |
| ---------------------------------------------- | -------------------------------------------------- |
| ดูรายชื่อนักกีฬาของสถาบันตัวเอง                   | เห็นนักกีฬาของสถาบันอื่น                             |
| ส่งออกรายชื่อเป็น CSV                            | อนุมัติหรือแก้ไขใบสมัคร (หัวหน้าฝ่ายทะเบียน สจล. ทำ)  |
| ดูกิจกรรม ประเภทกีฬา และสถานที่                   | เปลี่ยนสถาบันของบัญชี                                |
| ทำให้บัญชีที่ยังไม่ใช่ทีมงานเป็น Guest และเชิญเป็น Guest | สแกนเช็คอิน หรือเปิด Kiosk                         |
|                                                | ได้ที่นั่งหัวหน้า/รองหัวหน้า (ที่นั่งเป็นของ สจล.)    |

## งานหลัก

### ติดตามใบสมัครของสถาบัน

<Screenshot src="reg-other/athletes" alt="หน้านักกีฬาที่เห็นเฉพาะนักกีฬาของ มจธ." />

<Steps>
<Step>

### เปิดเมนู “นักกีฬา”

รายชื่อกรองเป็นสถาบันของคุณให้แล้ว เลือก **กีฬา** หรือ **สถานะ** เพื่อดูเฉพาะที่ต้องการ

</Step>
<Step>

### ตามคนที่ “ไม่อนุมัติ”

ใบสมัครที่ไม่ผ่านจะมีเหตุผลจากหัวหน้าฝ่ายทะเบียน แจ้งนักกีฬาให้แก้ข้อมูลแล้วส่งใหม่ในหน้า [สมัครกีฬา](/docs/participants/sports)

</Step>
<Step>

### กด “ส่งออก CSV”

ได้ไฟล์ที่เปิดใน Excel หรือ Google Sheets ได้ ใช้ทำรายชื่อส่งต้นสังกัดหรือเตรียมเสื้อแข่ง

</Step>
</Steps>

<Callout type="warn" title="รายชื่อว่างทั้งที่มีคนสมัคร?">
  ตรวจว่าบัญชีของคุณตั้งสถาบันถูก (ดูใต้ชื่อในเมนูบัญชี) ถ้าผิดหรือว่าง ให้สตาฟทะเบียน สจล. แก้ในหน้า “ผู้ใช้”
  และนักกีฬาที่ระบุสถาบันผิดจะไปอยู่ในรายชื่อของสถาบันอื่น ต้องให้หัวหน้าฝ่ายทะเบียนย้ายให้
</Callout>
