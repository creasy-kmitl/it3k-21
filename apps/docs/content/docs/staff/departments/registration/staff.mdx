<PageHero spot="staff-card">
  สตาฟทะเบียนของ สจล. ช่วยดูแลข้อมูลคนของทุกสถาบัน งานหลักคือ **ตั้งสถาบันให้บัญชีที่ระบุผิดหรือยังไม่ได้ระบุ**
  ดูรายชื่อนักกีฬาเพื่อตอบคำถาม และช่วยเช็คอินหน้างาน
</PageHero>

## เมนูที่คุณจะเห็น

<Screenshot src="reg-staff/sidebar" alt="เมนูของสตาฟทะเบียน สจล." />

นอกจาก [เครื่องมือพื้นฐาน](/docs/staff/basics/sidebar) คุณจะเห็น **ผู้ใช้** **กิจกรรม** **ประเภทกีฬา** **นักกีฬา** และ **สถานที่**

## คุณทำอะไรได้บ้าง

| ทำได้                                              | ทำไม่ได้ (ติดต่อหัวหน้าฝ่าย)                     |
| -------------------------------------------------- | ----------------------------------------------- |
| ตั้งสถาบันให้บัญชีใดก็ได้ (ยกเว้น Admin)              | ให้สถานะผู้เข้าร่วม นักกีฬา Staff หรือที่นั่ง      |
| ทำให้บัญชีที่ยังไม่ใช่ทีมงานเป็น Guest                 | อนุมัติหรือแก้ไขใบสมัครนักกีฬา                     |
| เชิญผู้ใช้เป็น Guest                                 | ส่งออก CSV                                       |
| ดูรายชื่อนักกีฬาทุกสถาบัน                             | สร้างหรือแก้กิจกรรม ประเภทกีฬา สถานที่            |
| สแกนเช็คอินและเปิด Kiosk                             | ส่งอีเมล                                         |

## งานหลัก

### ตั้งสถาบันของบัญชี

<Screenshot src="reg-staff/users" alt="หน้าผู้ใช้ของสตาฟทะเบียน สจล." />

<Steps>
<Step>

### ค้นหาบัญชีในหน้า “ผู้ใช้”

พิมพ์ชื่อในช่อง **ค้นหาชื่อ** หรือกรองตามฝ่าย

</Step>
<Step>

### กดแก้ไข แล้วเลือก “สถาบัน”

ช่องนี้ **ใช้กำหนดว่าฝ่ายทะเบียนเห็นนักกีฬาของสถาบันใด** และกำหนดว่าบัญชีนั้นสมัครกีฬาในนามสถาบันไหน

</Step>
<Step>

### บันทึก

</Step>
</Steps>

<Callout title="ทำไมผู้ใช้เปลี่ยนสถาบันเองไม่ได้">
  เมื่อผู้เข้าร่วมส่งโปรไฟล์แล้ว หรือบัญชีมีสถาบันแล้ว เจ้าของบัญชีเปลี่ยนเองไม่ได้ เพื่อกันการย้ายไปสมัครกีฬาในนามสถาบันอื่น
  ถ้าเลือกผิดจริง ให้ตรวจหลักฐาน (เช่น บัตรนักศึกษา) ก่อนเปลี่ยนให้
</Callout>

### ดูรายชื่อนักกีฬา

<Screenshot src="reg-staff/athletes" alt="หน้านักกีฬาของสตาฟทะเบียน สจล." />

กรองตามกีฬา สถานะ และสถาบัน หรือค้นด้วยชื่อหรือรหัสนักศึกษา การอนุมัติเป็นงานของหัวหน้า
ดูความหมายของแต่ละสถานะที่ [ตรวจใบสมัครนักกีฬา](/docs/staff/tasks/athletes)
