<PageHero spot="staff-card">
  ฝ่าย **ทะเบียน** ดูแลข้อมูลคน ทั้งบัญชีผู้ใช้ สถาบันของแต่ละบัญชี และใบสมัครนักกีฬา
  ฝ่ายนี้มีสตาฟจากหลายสถาบัน สิทธิ์จึงขึ้นกับ **ตำแหน่ง** และ **สถาบันของบัญชีคุณ** ด้วย สิทธิ์ผูกกับรหัสฝ่าย `registration`
</PageHero>

## สิทธิ์แยกตามตำแหน่ง

| งาน                                       | สตาฟ สจล.                  | สตาฟสถาบันอื่น              | หัวหน้า / รองหัวหน้า (สจล.) |
| ----------------------------------------- | -------------------------- | -------------------------- | -------------------------- |
| เครื่องมือพื้นฐาน (ปฏิทิน QR ลิงก์สั้น)     | ✓                          | ✓                          | ✓                          |
| หน้า “ผู้ใช้”                              | ให้ Guest + ตั้งสถาบัน       | ให้ Guest                   | ให้ทุกสถานะ ยกเว้น Admin     |
| ดูรายชื่อนักกีฬา                            | ทุกสถาบัน                   | เฉพาะสถาบันตัวเอง           | ทุกสถาบัน                   |
| ส่งออกรายชื่อนักกีฬา (CSV)                  |                            | ✓ (สถาบันตัวเอง)            | ✓                          |
| อนุมัติ / ไม่อนุมัติ / แก้ไขใบสมัคร           |                            |                            | ✓                          |
| กิจกรรม ประเภทกีฬา สถานที่                  | ดูอย่างเดียว                | ดูอย่างเดียว                | สร้าง แก้ไข ลบ              |
| สแกนเช็คอิน / Kiosk                        | ✓                          |                            | ✓                          |
| ส่งอีเมล                                   |                            |                            | ✓                          |
| เพิ่มและแก้ไขรายชื่อฝ่าย                     |                            |                            | ✓                          |
| จัดการที่นั่งหัวหน้าฝ่าย / โควตาพื้นที่          |                            |                            | ✓                          |

<Callout type="warn" title="สตาฟทะเบียนที่ยังไม่มีสถาบัน">
  ถ้าบัญชีของคุณยังไม่ได้ระบุสถาบัน ระบบจะไม่รู้ว่าคุณดูนักกีฬาของสถาบันไหนได้ จึงไม่แสดงเมนูกีฬาเลย
  ให้สตาฟทะเบียน สจล. หรือหัวหน้าฝ่ายตั้งสถาบันให้ในหน้า “ผู้ใช้”
</Callout>
