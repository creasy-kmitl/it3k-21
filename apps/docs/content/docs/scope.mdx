  เว็บไซต์ IT3Kings คือระบบกลางของมหกรรมกีฬาสานสัมพันธ์ 3 สถาบันพระจอมเกล้า
  ใช้ตั้งแต่ลงทะเบียนผู้เข้าร่วม สมัครกีฬา รับตั๋วและเช็คอินกิจกรรม จัดการแข่งขันและใส่คะแนนสด
  ไปจนถึงงานหลังบ้านของทีมงานทุกฝ่าย หน้านี้สรุปว่าระบบ**ทำอะไร** และ**ไม่ได้ทำอะไร**
  เพื่อให้ทุกฝ่ายเข้าใจขอบเขตตรงกัน ขอบเขตนี้อาจเปลี่ยนแปลงในอนาคต และจะแจ้งให้ทราบทุกครั้ง (ดู[ข้อ
  7](#7-แผนในอนาคตและการเปลี่ยนแปลงขอบเขต))

## 1. วัตถุประสงค์

1. **รวมข้อมูลผู้เข้าร่วมไว้ที่เดียว** แทนแบบฟอร์มและไฟล์ที่กระจายอยู่หลายที่ ลดการกรอกข้อมูลซ้ำ
2. **ให้แต่ละสถาบันสมัครนักกีฬาและตรวจคุณสมบัติได้เอง** ภายใต้กติกาเดียวกัน
3. **จัดการแข่งขันได้ครบวงจร** ตั้งแต่จัดทีม ตารางแข่ง รายงานตัว ใส่คะแนน จนถึงอันดับและเหรียญ
4. **ประกาศผลการแข่งขันแบบเรียลไทม์** ให้ทุกคนดูได้โดยไม่ต้องเข้าสู่ระบบ
5. **เป็นเครื่องมือทำงานร่วมกันของทีมงาน 16 ฝ่าย** เช่น ปฏิทิน ช่องทางติดต่อหัวหน้าฝ่าย และการส่งอีเมล
6. **ดูแลข้อมูลส่วนบุคคลอย่างปลอดภัย** ตาม[นโยบายการเก็บรักษาข้อมูล](/docs/privacy)

## 2. ผู้ใช้งาน

| กลุ่มผู้ใช้               | ใครบ้าง                                                 | ต้องเข้าสู่ระบบไหม | ใช้ทำอะไรเป็นหลัก                            |
| ------------------------- | ------------------------------------------------------- | ------------------ | -------------------------------------------- |
| ผู้ชมทั่วไป               | ใครก็ได้                                                | ไม่ต้อง            | ดูกิจกรรม กติกา ตารางแข่ง ผลสด และตารางคะแนน |
| Guest                     | ผู้ที่เข้าสู่ระบบครั้งแรกและยังไม่ได้กรอกโปรไฟล์        | ต้อง               | กรอกโปรไฟล์เพื่อเป็นผู้เข้าร่วม              |
| ผู้เข้าร่วม (Participant) | นักศึกษาและบุคลากรของ 3 สถาบันที่ส่งโปรไฟล์แล้ว         | ต้อง               | รับตั๋ว เช็คอินกิจกรรม                       |
| นักกีฬา (Athlete)         | ผู้เข้าร่วมที่สมัครแข่งกีฬาในนามสถาบัน                  | ต้อง               | สมัครกีฬา ติดตามผลการตรวจ รายงานตัวก่อนแข่ง  |
| ทีมงาน (Staff)            | สตาฟของ 16 ฝ่าย                                         | ต้อง               | งานของฝ่ายตัวเองในระบบทีมงาน (`/staff`)      |
| หัวหน้าและรองหัวหน้าฝ่าย  | ทีมงานที่ได้ที่นั่งหัวหน้า (เป็นบัญชีของ สจล. เท่านั้น) | ต้อง               | งานของทีมงาน และสิทธิ์เพิ่มตามฝ่าย           |
| ผู้ดูแลระบบ (Admin)       | ผู้ดูแลระบบที่ได้รับมอบหมาย                             | ต้อง               | ทุกอย่างในระบบ รวมถึงดูมุมมองของบัญชีอื่น    |
| นักพัฒนา                  | ผู้ดูแลโค้ดและโครงสร้างพื้นฐาน                          | —                  | พัฒนา ทดสอบ และ deploy ระบบ                  |

สถาบันที่ระบบรองรับมี 4 แห่ง ได้แก่ สจล., มจธ., มจพ. วิทยาเขตกรุงเทพฯ และ มจพ. วิทยาเขตปราจีนบุรี
บัญชีที่ใช้อีเมลของ `kmitl.ac.th`, `kmutt.ac.th` หรือ `kmutnb.ac.th` เข้าสู่ระบบครั้งแรกได้เอง ส่วนอีเมลอื่นต้องได้รับคำเชิญจากทีมงาน

| คู่มือ (เว็บไซต์นี้) | `it3k-docs.creasy.club`     | วิธีใช้งานสำหรับผู้เข้าร่วม ทีมงาน และนักพัฒนา และนโยบายต่าง ๆ    |
| ลิงก์ย่อ             | `it3k.creasy.club/l/<ชื่อ>` | ลิงก์สั้นของงานที่เปลี่ยนปลายทางได้ภายหลัง                        |

และ**เว็บทดสอบของแต่ละ pull request** ดูรายละเอียดที่[โครงสร้างระบบ](/docs/developers/architecture)

## 4. สิ่งที่อยู่ในขอบเขต

### 4.1 หน้าสาธารณะ (ไม่ต้องเข้าสู่ระบบ)

| หน้า        | ที่อยู่      | ทำอะไรได้                                                         |
| ----------- | ------------ | ----------------------------------------------------------------- |
| หน้าแรก     | `/`          | ภาพรวมของงานและทางเข้าสู่การลงทะเบียน                             |
| กิจกรรม     | `/events`    | รายการกิจกรรม วันเวลา สถานที่พร้อมแผนที่นำทาง และรายละเอียด       |
| กีฬา        | `/sports`    | กีฬาและประเภทย่อยที่แข่ง พร้อมกติกาการแข่งขัน                     |
| ตารางแข่ง   | `/matches`   | โปรแกรมแข่ง ผลแต่ละแมตช์ รายชื่อผู้เล่น กรรมการ และรูปภาพ         |
| ถ่ายทอดผลสด | `/live`      | คะแนนของแมตช์ที่กำลังแข่ง อัปเดตแบบเรียลไทม์                      |
| ตารางคะแนน  | `/standings` | ตารางคะแนนกลุ่ม สายน็อกเอาต์ อันดับ และเหรียญรางวัลของแต่ละสถาบัน |

ดูวิธีใช้ที่[ผลการแข่งขัน](/docs/participants/results)

### 4.2 ผู้เข้าร่วม

- เข้าสู่ระบบด้วยบัญชี Google ([เริ่มต้นใช้งาน](/docs/participants/getting-started))
- กรอกโปรไฟล์ผู้เข้าร่วม ได้แก่ ข้อมูลส่วนตัว รูปยืนยันตัวตน และข้อมูลสุขภาพ (บันทึกร่างอัตโนมัติ) ([โปรไฟล์](/docs/participants/profile))
- ค้นหากิจกรรม รับตั๋ว เลือกประเภทตั๋ว และยกเลิกตั๋ว รวมถึงรับตั๋วผ่านลิงก์เฉพาะของกิจกรรม ([กิจกรรมและตั๋ว](/docs/participants/events-and-tickets))
- เปิด QR ของตั๋ว หรือบาร์โค้ดรหัสผู้ใช้ ให้ทีมงานสแกนเข้ากิจกรรม ([เช็คอิน](/docs/participants/check-in))

### 4.3 นักกีฬา

- สมัครแข่งกีฬาในนามสถาบัน แนบรหัสและรูปบัตรนักศึกษา และกรอกข้อมูลเฉพาะของกีฬา เช่น เบอร์เสื้อ มือแบดมินตัน หรือข้อมูลบัญชีเกม ([สมัครกีฬา](/docs/participants/sports))
- ติดตามผลการตรวจใบสมัคร (รอตรวจ อนุมัติ หรือไม่อนุมัติพร้อมเหตุผล) และแก้ไขก่อนได้รับการตรวจ
- เชื่อมบัญชี Discord สำหรับกีฬา E-Sports
- รายงานตัวก่อนลงแข่งแต่ละแมตช์ด้วยรหัสเช็คอินกีฬา 6 หลัก ([รายงานตัวแมตช์](/docs/participants/match-checkin))

### 4.4 ทีมงานทุกฝ่าย

| เครื่องมือ  | ทำอะไรได้                                                                 |
| ----------- | ------------------------------------------------------------------------- |
| แดชบอร์ด    | กำหนดการของแผนกใน 7 วันข้างหน้า และทางลัดไปหน้าที่ใช้บ่อย                 |
| ปฏิทินแผนก  | จัดการกำหนดการ ชวนฝ่ายอื่นร่วมงาน รับการแจ้งเตือน และดูประวัติการแก้ไข    |
| หัวหน้าฝ่าย | ดูหัวหน้าและรองหัวหน้าของแต่ละฝ่าย และเปิดดูช่องทางติดต่อตามสิทธิ์        |
| QR Code     | ออกแบบ QR สำหรับสื่อของงาน ใส่โลโก้ และใช้ Preset ร่วมกันในทีม            |

### 4.5 งานเฉพาะฝ่าย

สิทธิ์ในส่วนนี้ขึ้นกับฝ่าย ตำแหน่ง และสถาบันของบัญชี ตารางสรุปเฉพาะฝ่ายหลัก (Admin ทำได้ทุกอย่าง)
สตาฟทะเบียนและสตาฟฝ่ายกีฬาของสถาบันอื่นไม่เห็นระบบแข่งขัน ดูรายละเอียดว่าใครทำอะไรได้ที่[บทบาทและสิทธิ์ของทีมงาน](/docs/staff/overview)

| งาน                | ฝ่ายที่ใช้หลัก                   | ทำอะไรได้                                                                                    |
| ------------------ | -------------------------------- | -------------------------------------------------------------------------------------------- |
| บัญชีผู้ใช้        | Tech/Live, ทะเบียน               | ค้นหาบัญชี กำหนดบทบาท ฝ่าย สถาบัน และโควตาพื้นที่                                            |
| คำเชิญ             | Tech/Live, ทะเบียน               | เชิญคนที่ไม่มีอีเมลสถาบัน พร้อมกำหนดบทบาท ฝ่าย สถาบัน และที่นั่งไว้ล่วงหน้า                  |
| ที่นั่งหัวหน้าฝ่าย | หัวหน้า Tech/Live และทะเบียน     | เพิ่ม แก้ไข ย้าย และลบที่นั่งหัวหน้าและรองหัวหน้า                                            |
| ฝ่ายของงาน         | หัวหน้าฝ่ายทะเบียน, Admin        | เพิ่มฝ่าย แก้ชื่อ สี และไอคอน (รหัสฝ่ายเปลี่ยนไม่ได้)                                        |
| ตรวจใบสมัครนักกีฬา | ทะเบียน, Tech/Live               | กรอง อนุมัติทีละคนหรือหลายคน ไม่อนุมัติพร้อมเหตุผล ย้ายสถาบัน และส่งออก CSV ตามสถาบันที่ดูแล |
| กีฬาและประเภทย่อย  | หัวหน้า Tech/Live และทะเบียน     | เพิ่มกีฬา เปิดหรือปิดรับสมัคร และกำหนดข้อมูลที่นักกีฬาต้องกรอก                               |
| กิจกรรมและตั๋ว     | หัวหน้า Tech/Live และทะเบียน     | สร้างกิจกรรม เขียนเนื้อหา กำหนดประเภทตั๋ว จำนวน และผู้ที่มีสิทธิ์รับ                         |
| สถานที่            | หัวหน้า Tech/Live และทะเบียน     | เพิ่มสถานที่พร้อมหมุดบนแผนที่                                                                |
| เช็คอินกิจกรรม     | Tech/Live, ทะเบียน               | สแกนตั๋วด้วยมือถือหรือโหมด kiosk บังคับเช็คอิน และยกเลิกการเช็คอิน                           |
| ตั้งค่าการแข่งขัน  | Tech/Live, หัวหน้าทะเบียนและกีฬา | จำนวนคนต่อทีม รายชื่อลงแข่ง วิธีนับคะแนน ตารางคะแนน เหรียญ และเวลารายงานตัว                  |

| จัดการแข่งขัน      | Tech/Live, หัวหน้าทะเบียนและกีฬา | สร้างแมตช์และสายน็อกเอาต์ กำหนดเวลา สนาม กรรมการ และรายชื่อลงแข่ง                            |

| ใส่คะแนนสด         | Tech/Live, ทะเบียน, ฝ่ายกีฬา     | ใส่คะแนนจากข้างสนามด้วยมือถือ ใช้ต่อได้ตอนเน็ตหลุด จบแมตช์ และบันทึกผลพิเศษ                  |
| แก้กติกาการแข่งขัน | Tech/Live, ทะเบียน, หัวหน้ากีฬา  | เขียนกติกาของกีฬาหรือของแต่ละประเภทเป็น Markdown                                             |
| ส่งอีเมล           | Tech/Live, หัวหน้าฝ่ายทะเบียน    | เขียนอีเมลพร้อมรูป เลือกกลุ่มผู้รับ ดูตัวอย่าง และดูประวัติการส่ง                            |

### 4.6 ผู้ดูแลระบบ

- ทำได้ทุกอย่างที่ฝ่ายอื่นทำได้ รวมถึงให้บทบาท Admin
- ใช้ “ดูในฐานะ” เพื่อดูว่าบทบาทหรือบัญชีหนึ่งเห็นอะไร แบบดูอย่างเดียว หรือสวมบัญชีชั่วคราวไม่เกิน 1 ชั่วโมงเพื่อช่วยแก้ปัญหา ([ดูในฐานะ](/docs/staff/admin/view-as))

### 4.7 งานที่ระบบทำเองเบื้องหลัง

- ส่งอีเมลผ่านคิว (คำเชิญ อีเมลยืนยันการส่งโปรไฟล์ และอีเมลจากทีมงาน) และส่งซ้ำเมื่อส่งไม่สำเร็จ
- ทุกชั่วโมง: ลบไฟล์ที่อัปโหลดไม่สำเร็จ ลบเซสชันที่หมดอายุ ปิดการสวมบัญชีที่เกินเวลา
  และลบข้อมูลส่วนบุคคลที่ครบกำหนด 1 ปีหลังวันสิ้นสุดงาน ([นโยบายการเก็บรักษาข้อมูล](/docs/privacy))
- บันทึกประวัติการแก้ไขและ audit log เพื่อตรวจสอบย้อนหลัง

## 6. ข้อจำกัดและสมมติฐาน

- ผู้ใช้ทุกคนที่ต้องเข้าสู่ระบบต้องมี**บัญชี Google** ระบบไม่มีการเข้าสู่ระบบด้วยรหัสผ่าน
- รายชื่อสถาบันและโดเมนอีเมลที่สมัครเองได้กำหนดไว้ในโค้ด การเพิ่มสถาบันใหม่ต้องแก้โค้ดและ deploy
- ที่นั่งหัวหน้าและรองหัวหน้าฝ่ายเป็นของบัญชี สจล. เท่านั้น เพราะ สจล. เป็นเจ้าภาพ
- หน้าจอทั้งหมดเป็นภาษาไทย
- ต้องเชื่อมต่ออินเทอร์เน็ต ยกเว้นการใส่คะแนนสดซึ่งเก็บคะแนนไว้ในเครื่องตอนเน็ตหลุด แล้วส่งให้เมื่อเน็ตกลับมา
- ระบบรองรับงาน IT3Kings ทีละปี ข้อมูลส่วนบุคคลของปีก่อนจะถูกลบตามนโยบาย ส่วนผลการแข่งขันเก็บไว้เป็นประวัติ

## 7. แผนในอนาคตและการเปลี่ยนแปลงขอบเขต

ขอบเขตในหน้านี้คือสิ่งที่ระบบทำได้ ณ วันที่เขียน และ**อาจเปลี่ยนแปลงในอนาคต** เมื่อเพิ่มหรือเลิกใช้ฟีเจอร์ใด หน้านี้จะได้รับการปรับปรุงด้วย

| ฟีเจอร์ที่วางแผนไว้ | รายละเอียด                                                                                                                    | สถานะ                |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| Google Analytics    | นับสถิติการเข้าชมเว็บไซต์ เพื่อปรับปรุงเว็บและวัดผลการประชาสัมพันธ์ ทำงานเฉพาะกับผู้ที่กดยอมรับคุกกี้วิเคราะห์                | กำลังจะติดตั้ง       |
| อัลบั้มภาพกิจกรรม   | ทีมงานที่ได้รับมอบหมายอัปโหลดภาพบรรยากาศของกิจกรรมและการแข่งขัน ให้ทุกคนดูได้ในเว็บไซต์ คนในภาพขอให้ลบหรือเบลอภาพของตัวเองได้ | วางแผน ยังไม่เปิดใช้ |

ฟีเจอร์ใหม่ที่เก็บหรือเผยแพร่ข้อมูลส่วนบุคคลเพิ่ม เช่น Google Analytics และอัลบั้มภาพกิจกรรม ต้องเป็นไปตาม[นโยบายการเก็บรักษาข้อมูล](/docs/privacy)
(กติกาภาพถ่ายกิจกรรมอยู่ที่[ข้อ 6.2](/docs/privacy#62-ภาพถ่ายกิจกรรม-กำลังจะเพิ่มในอนาคต))
และถ้าการเปลี่ยนแปลงกระทบข้อมูลของผู้ใช้ **จะแจ้งให้ทราบล่วงหน้า**ตาม[ข้อ 15 ของนโยบาย](/docs/privacy#15-การเปลี่ยนแปลงนโยบาย)
