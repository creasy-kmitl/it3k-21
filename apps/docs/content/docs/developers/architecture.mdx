## รูปแบบของ router

ทุก router เป็น factory `createXRoutes(deps: RouteDeps)` โดย `RouteDeps = { getSession, getDb }`
production ส่ง session ของ Better Auth และ D1 เข้ามา ส่วนเทสต์ส่ง session ปลอมและ DB ในหน่วยความจำ

- `requireUser` โหลดบทบาท ฝ่าย ที่นั่ง และสถานะระงับจาก DB **ทุก request**
- `requireJsonPosts` คือตัวกัน CSRF: คุกกี้เป็น `SameSite=None` ทุก POST จึงต้องเป็น `application/json`
- ตรวจ input ด้วย `validate(target, zodSchema)` ตอบ 400 เป็น `{ message, issues }`

## เขียนแบบกัน race

route อ่านสถานะก่อน แล้วเขียนทั้งหมดใน `db.batch([...])` ครั้งเดียว (เป็น transaction เดียวใน D1)
`abortUnless(db, userId, condition)` อยู่ต้น batch ถ้าสิ่งที่อ่านไว้เปลี่ยน batch จะล้มและตอบ `"stale"`
ทุกการเขียนที่ขึ้นกับสิ่งที่อ่านไว้ก่อนต้องใช้รูปแบบนี้

## เว็บ ↔ API

- router export `type XRoutes = ReturnType<typeof createXRoutes>` เว็บ import type นี้แล้วสร้าง `hono/client` ที่มีชนิดข้อมูล
  เปลี่ยน response ฝั่ง server แล้ว type ฝั่งเว็บตามอัตโนมัติ
- หน้าเว็บได้ client ผ่าน `useApis()` เทสต์สลับเป็นของปลอมด้วย `ApiProvider`
- `clearCacheOnUserChange` ล้าง Query cache เมื่อผู้ใช้เปลี่ยน เพราะข้อมูลอย่าง `canEdit` เป็นของผู้ใช้แต่ละคน
