## สามส่วนของสิทธิ์

| ส่วน    | เก็บที่                                  | helper                                                                   |
| ------- | ---------------------------------------- | ------------------------------------------------------------------------ |
| บทบาท   | `user.role` สตริงคั่นด้วยจุลภาค          | `parseRoles`, `hasRole`, `isMember` (`packages/auth/src/permissions.ts`) |
| ฝ่าย    | `user.departmentId` → `department.code`  | `hasCapability(code, capability)`                                        |
| ที่นั่ง | ตาราง `leadership` (`head` / `vicehead`) | `mayHoldSeat(institution)`                                               |

`isMember` = `staff` หรือ `admin` ที่นั่งให้สิทธิ์เฉพาะบัญชีของ สจล. (`HOST_INSTITUTION`)

## Department capabilities

`apps/server/src/policies/department-capabilities.ts`

| รหัส           | capabilities                                                                           |
| -------------- | -------------------------------------------------------------------------------------- |
| `tech-live`    | `manageAccounts`, `manageShortLinks`, `runSports`, `sendEmail`                         |
| `registration` | `manageAccounts`, `registerAthletes`, `sendEmailAsLeader`, `manageDepartmentsAsLeader` |
| `sports`       | `assistSports`                                                                         |

เฉพาะรหัสใน `RESERVED_DEPARTMENT_CODES` (`packages/db/src/department-codes.ts`) ที่ให้สิทธิ์ได้ และ API ไม่ยอมให้ตั้งรหัสเหล่านี้
รหัสฝ่ายถูกล็อกด้วย trigger จาก `lock_department_codes` เปลี่ยนไม่ได้และลบฝ่ายที่มีรหัสไม่ได้ ไม่ว่าทาง API, Drizzle Studio หรือ SQL

## Policies

route ถาม policy เสมอ ห้ามเช็กบทบาท ที่นั่ง รหัส หรือสถาบันตรง ๆ แต่ละ policy มีคู่ SQL `…IsAsRead` สำหรับ `abortUnless`

| ไฟล์             | ตัดสินเรื่อง                                                                  |
| ---------------- | ----------------------------------------------------------------------------- |
| `leadership.ts`  | ที่นั่ง ช่องทางติดต่อ ใครให้สถานะอะไรได้ (`canAssign`, `hasFullAssignRights`) |
| `sports.ts`      | `sportAccess` → ชุด permission + ขอบเขตสถาบัน                                 |
| `departments.ts` | ใครจัดการรายชื่อฝ่าย                                                          |
| `email.ts`       | ใครส่งอีเมล                                                                   |
| `short-links.ts` | ใครสร้างและแก้ลิงก์สั้น / Preset QR                                           |
| `calendar.ts`    | ใครแก้ปฏิทินของฝ่ายไหน                                                        |

### ระบบกีฬา (`sportAccess`)

| ผู้ใช้                                                        | permissions                                                                                                                    | ขอบเขต       |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| admin, หัวหน้า/รอง `runSports` หรือ `registerAthletes` (สจล.) | ทั้งหมด                                                                                                                        | ทุกสถาบัน    |
| สตาฟ `runSports`                                              | `kiosk.operate`, `athletes.read`, `rules.edit` + แข่งขันทั้งหมด                                                                | ทุกสถาบัน    |
| สตาฟ `registerAthletes` สจล.                                  | `kiosk.operate`, `athletes.read`, `rules.edit`, `competition.read`, `matches.score`, `matches.checkin`, `users.setInstitution` | ทุกสถาบัน    |
| สตาฟ `registerAthletes` สถาบันอื่น                            | `athletes.read`, `athletes.export`                                                                                             | สถาบันตัวเอง |
| สตาฟ `registerAthletes` ไม่มีสถาบัน                           | —                                                                                                                              | —            |
| หัวหน้า/รอง `assistSports` (สจล.)                             | `rules.edit` + แข่งขันทั้งหมด                                                                                                  | ทุกสถาบัน    |
| สตาฟ `assistSports` สจล.                                      | `competition.read`, `matches.score`                                                                                            | ทุกสถาบัน    |
| สตาฟ `assistSports` สถาบันอื่น                                | —                                                                                                                              | —            |

"แข่งขันทั้งหมด" คือ `competition.read`, `teams.manage`, `matches.manage`, `matches.score` และ `matches.checkin`
แยกจาก `kiosk.operate` เพื่อให้ฝ่ายกีฬาจัดการแข่งได้โดยไม่ได้ Kiosk เช็คอินของกิจกรรมไปด้วย

</Step>
