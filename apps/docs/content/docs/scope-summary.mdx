## เว็บไซต์นี้คืออะไร

ระบบกลางของงาน IT3Kings มหกรรมกีฬาสานสัมพันธ์ของ 3 สถาบันพระจอมเกล้า (สจล. มจธ. และ มจพ.)
ใช้ตั้งแต่ลงทะเบียน สมัครแข่ง รับตั๋ว ไปจนถึงจัดการแข่งขันและประกาศผล

## ใครใช้ ใช้ทำอะไร

| ใคร                | ใช้ทำอะไร                                                          |
| ------------------ | ------------------------------------------------------------------ |
| **ทุกคน**          | ดูกิจกรรม กติกา ตารางแข่ง ผลสด และตารางคะแนน โดยไม่ต้องเข้าสู่ระบบ |
| **ผู้เข้าร่วม**    | กรอกโปรไฟล์ รับตั๋ว และเช็คอินเข้ากิจกรรม                          |
| **นักกีฬา**        | สมัครแข่งในนามสถาบัน ติดตามผลการตรวจ และรายงานตัวก่อนลงแข่ง        |
| **ทีมงาน**         | ปฏิทินของฝ่าย ติดต่อหัวหน้าฝ่าย สร้าง QR Code และลิงก์ย่อ          |
| **ฝ่ายทะเบียน**    | ตรวจใบสมัครนักกีฬาและดูแลบัญชีผู้ใช้                               |
| **ฝ่ายกีฬา**       | จัดทีม จัดตารางแข่ง เช็คอินนักกีฬา และใส่คะแนนจากข้างสนาม          |
| **ฝ่าย Tech/Live** | ดูแลบัญชีผู้ใช้ กิจกรรม ตั๋ว การเช็คอินหน้างาน และส่งอีเมล         |

เข้าสู่ระบบด้วย**บัญชี Google** ถ้าใช้อีเมลของ 3 สถาบันเข้าได้เลย ส่วนอีเมลอื่นต้องได้รับคำเชิญจากทีมงานก่อน

## เว็บไซต์ไม่ได้ทำอะไร

- ไม่รับชำระเงินหรือขายตั๋ว (ตั๋วเป็นสิทธิ์เข้ากิจกรรม ไม่มีราคา)
- ไม่เปิดให้บุคคลทั่วไปนอก 3 สถาบันสมัครเอง
- ไม่ถ่ายทอดสดวิดีโอ (มีแค่คะแนนสด)
- ไม่มีแชต
- ไม่ใช่เวชระเบียน ข้อมูลสุขภาพใช้แค่เตรียมการปฐมพยาบาลและอาหาร
- ไม่จองที่พัก การเดินทาง หรือจัดการงบประมาณ
- ไม่มีแอปให้ติดตั้ง ใช้ผ่านเบราว์เซอร์ได้เลย
- ไม่แสดงโฆษณา

## กำลังจะเพิ่ม

- **Google Analytics** นับสถิติการเข้าชมเว็บ ทำงานเฉพาะเมื่อคุณกดยอมรับ
- **อัลบั้มภาพกิจกรรม** ภาพบรรยากาศงานและการแข่งขัน

ขอบเขตนี้**อาจเปลี่ยนในอนาคต** และเมื่อเปลี่ยนในส่วนที่กระทบข้อมูลของคุณ**จะแจ้งให้ทราบก่อน**
ดูว่าเราดูแลข้อมูลของคุณอย่างไรได้ที่[นโยบายข้อมูลฉบับย่อ](/docs/privacy-summary)
