<PageHero spot="crown">
  **IT3Kings** คือมหกรรมแข่งขันกีฬาสานสัมพันธ์ของนักศึกษาด้านเทคโนโลยีสารสนเทศจาก 3 สถาบันพระจอมเกล้า
  (สจล. มจธ. และ มจพ.) คู่มือนี้อธิบายวิธีใช้เว็บไซต์ของงาน ตั้งแต่ลงทะเบียน รับตั๋ว สมัครกีฬา
  ไปจนถึงงานของทีมงานแต่ละฝ่าย
</PageHero>

## ฉันคือใคร?

เลือกหน้าที่ตรงกับคุณ ถ้าไม่แน่ใจว่าตัวเองมีบทบาทอะไร ให้ดูมุมขวาบนของเว็บ (หรือมุมซ้ายล่างในระบบทีมงาน)
ใต้ชื่อของคุณจะมีบทบาทเขียนไว้ เช่น “ผู้เข้าร่วม” “นักกีฬา” หรือ “Staff · Art”

<RoleCards>
  <RoleCard spot="phone-qr" title="ผู้เข้าร่วม" href="/docs/participants/getting-started">
    เข้าสู่ระบบ กรอกโปรไฟล์ รับตั๋ว และเช็คอิน
  </RoleCard>
  <RoleCard spot="medal" title="นักกีฬา" href="/docs/participants/sports">
    สมัครแข่งกีฬาในนามสถาบัน และติดตามผลการตรวจ
  </RoleCard>
  <RoleCard spot="headset" title="สตาฟฝ่าย Tech/Live" href="/docs/staff/departments/tech-live">
    ดูแลบัญชีผู้ใช้ ระบบกีฬา เช็คอิน และส่งอีเมล
  </RoleCard>
  <RoleCard spot="staff-card" title="สตาฟฝ่ายทะเบียน" href="/docs/staff/departments/registration">
    ตรวจใบสมัครนักกีฬา กำหนดสถาบัน และดูแลฝ่าย
  </RoleCard>
  <RoleCard spot="whistle" title="สตาฟฝ่ายกีฬา" href="/docs/staff/departments/sports">
    จัดทีม ตารางแข่ง เช็คอินนักกีฬา และใส่คะแนน
  </RoleCard>
  <RoleCard spot="megaphone" title="สตาฟฝ่ายอื่น ๆ" href="/docs/staff/departments/others">
    ปฏิทินแผนก รายชื่อหัวหน้าฝ่าย QR Code และลิงก์สั้น
  </RoleCard>
  <RoleCard spot="server" title="นักพัฒนา" href="/docs/developers/setup">
    ติดตั้งโปรเจกต์ โครงสร้างระบบ และการ deploy
  </RoleCard>
</RoleCards>
