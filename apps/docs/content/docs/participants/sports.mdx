## หน้าสมัครกีฬา

ด้านบนบอกว่าคุณสมัคร “ในนาม” สถาบันใด ด้านล่างคือรายการ **การสมัครของฉัน** พร้อมสถานะของแต่ละใบ

| อนุมัติแล้ว  | ผ่านแล้ว ถ้าต้องแก้ข้อมูล ให้ติดต่อฝ่ายทะเบียน                              |
| ไม่อนุมัติ   | ไม่ผ่าน อ่านเหตุผลที่ฝ่ายทะเบียนเขียนไว้ แล้วแก้ไขตามนั้น                   |

## สมัครประเภทใหม่

<Steps>
<Step>

### กด “สมัครกีฬา”

หน้าต่าง **เลือกกีฬาที่จะสมัคร** จะเปิดขึ้น ค้นหาได้ เช่น “ฟุตบอล” “ROV” หรือ “หญิง”
แต่ละประเภทบอกเพศและรูปแบบ (เดี่ยว / คู่ / ทีม)

</Step>
<Step>

### กด “สมัคร” ที่ประเภทที่ต้องการ

ทุกครั้งต้องมี **รหัสนักศึกษา** และ **รูปบัตรนักศึกษา** (ด้านหน้าบัตร เห็นชื่อ รหัส และรูปชัดเจน)
ครั้งแรกกรอกรหัสแล้วกด **แนบรูปบัตรนักศึกษา** เพื่ออัปโหลดหรือเลือกรูปจากคลังไฟล์
ครั้งต่อไประบบกรอกรหัสและแนบรูปเดิมให้เอง แก้รหัสหรือกด **เปลี่ยนรูปบัตรนักศึกษา** ได้ถ้าไม่ถูกต้อง

จากนั้นกรอกข้อมูลเพิ่มตามกีฬา

- ฟุตบอล บาสเกตบอล: **เบอร์เสื้อ** (ห้ามซ้ำกับเพื่อนร่วมทีมในสถาบันเดียวกัน)
- แบดมินตันเดี่ยว: **มือ 1** หรือ **มือ 2**
- Esports: **ชื่อในเกม (IGN)** คำอ่าน ลิงก์ Facebook และต้อง **เชื่อม Discord**

</Step>
<Step>

### ส่งใบสมัคร

ระบบส่งอีเมล “ส่งใบสมัคร … แล้ว” และแสดงใบสมัครในรายการเป็น **รอตรวจสอบ**
เมื่อฝ่ายทะเบียนตรวจแล้วจะได้อีเมลแจ้งผลอีกครั้ง

</Step>
</Steps>

## เชื่อม Discord (Esports)

กีฬา Esports ต้องเชื่อมบัญชี Discord ก่อนสมัคร เพื่อให้ทีมงานติดต่อและจัดห้องแข่งได้

1. ในหน้าสมัครประเภท Esports กด **เชื่อม Discord**
2. อนุญาตในหน้าของ Discord แล้วระบบพากลับมา จะขึ้นว่า **เชื่อมแล้ว: ชื่อผู้ใช้ของคุณ**
3. ระบบพาคุณเข้าเซิร์ฟเวอร์ Discord Esport ของงานให้เลย แล้วบอทจะให้ยศเกม ยศทีมสถาบัน และตั้งชื่อในเซิร์ฟเวอร์ให้เอง
   ถ้ายังไม่เห็นเซิร์ฟเวอร์ใน Discord ไปที่หน้า **โปรไฟล์** แล้วกด **เข้าเซิร์ฟเวอร์ Discord** ในการ์ด Discord Esport
4. ถ้าเชื่อมผิดบัญชี กด **ยกเลิกการเชื่อม** แล้วเชื่อมใหม่

<Callout type="warn">
  หนึ่งบัญชี Discord เชื่อมกับบัญชี IT3Kings ได้บัญชีเดียว และใช้ Discord เข้าสู่ระบบไม่ได้
  ถ้าขึ้นว่า “ยังไม่เปิดให้เชื่อม Discord” แปลว่าทีมงานยังไม่เปิดระบบนี้ ให้รอประกาศ
</Callout>

## แก้ไขหรือถอนการสมัคร

ใบสมัครที่ **รอตรวจสอบ** มีปุ่มดินสอ (แก้ไข) และถังขยะ (**ถอนการสมัคร**) ด้านขวา
หลังอนุมัติแล้วแก้เองไม่ได้ ให้ติดต่อฝ่ายทะเบียน

## หลังได้รับอนุมัติ

- รับตั๋ว **นักกีฬา** ของนัดที่คุณลงแข่งได้ที่หน้า [กิจกรรม](/docs/participants/events-and-tickets)
- ตั๋วบางประเภทเปิดเฉพาะนักกีฬาที่อนุมัติแล้วในกีฬานั้น หรือเฉพาะนักกีฬาในรายชื่อของนัดนั้น
- ทีมงานจะจัดคุณเข้าทีมของมหาลัย แล้วสร้างแมตช์ ดูโปรแกรม ผลสด และตารางคะแนนได้ที่ [ผลการแข่งขัน](/docs/participants/results)
- ก่อนลงแข่งทุกแมตช์ ให้ [รายงานตัวเข้าแข่งขัน](/docs/participants/match-checkin) ที่ kiosk ของแมตช์ ด้วยรหัสเช็คอินกีฬาในหน้าโปรไฟล์
