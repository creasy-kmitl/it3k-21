## ค้นหากิจกรรม

เปิดหน้า **กิจกรรม** (`/events`) จากเมนูด้านบน หรือปุ่ม “ค้นหากิจกรรม” ที่หน้าแรก
กรองได้ด้วยแท็บ **ทั้งหมด** **กิจกรรมกีฬา** **กิจกรรมทั่วไป** และ **มีตั๋วแล้ว**

<Screenshot
  src="participant/events"
  mobile="participant/events-mobile"

/>

ปุ่มที่การ์ดกิจกรรมบอกสถานะของตั๋ว

| ปุ่ม / ป้าย             | ความหมาย                                            |
| ----------------------- | --------------------------------------------------- |
| รับตั๋ว                 | กดเพื่อรับตั๋วได้ทันที                              |
| เลือกประเภทตั๋ว (n)     | กิจกรรมนี้มีตั๋วหลายประเภท กดเพื่อเลือก             |
| รับตั๋วแล้ว             | คุณมีตั๋วของกิจกรรมนี้แล้ว                          |
| ตั๋วเต็มแล้ว            | ตั๋วถูกรับครบจำนวน                                  |
| ปิดรับแล้ว              | ทีมงานปิดการรับตั๋ว หรือกิจกรรมจบแล้ว                |

## รับตั๋ว

<Steps>
<Step>

### เปิดหน้ากิจกรรม

กดที่การ์ดกิจกรรมเพื่อดูรายละเอียด วันเวลา สถานที่ และเนื้อหาเต็ม

</Step>
<Step>

### เลือกประเภทตั๋วแล้วกด “รับตั๋ว”

บางกิจกรรมมีหลายประเภท เช่น “ผู้เข้าร่วม” “กองเชียร์” หรือ “นักกีฬา” แต่ละประเภทบอกจำนวนที่เหลือ
และจำนวนที่รับได้ต่อคน ถ้าประเภทนั้นให้รับได้หลายใบ ปุ่มจะเปลี่ยนเป็น **รับเพิ่ม** จนครบจำนวน (**รับครบแล้ว**)

</Step>
<Step>

### ตรวจอีเมล

ระบบส่งอีเมล “ตั๋ว … ของคุณ” พร้อม QR ไว้ให้ด้วย แต่แนะนำให้เปิดตั๋วจากเว็บที่หน้างาน เพราะเป็นข้อมูลล่าสุด

</Step>
</Steps>

### ทำไมรับตั๋วบางประเภทไม่ได้

ทีมงานกำหนดได้ว่าตั๋วแต่ละประเภทเปิดให้ใครบ้าง ถ้าไม่ตรงเงื่อนไข ปุ่มจะกดไม่ได้

- **บทบาท** เช่น ตั๋ว “ทีมงาน” สำหรับสตาฟเท่านั้น
- **สถาบัน** เช่น เฉพาะ สจล. และ มจธ.
- **กีฬา** เฉพาะนักกีฬาที่ใบสมัครกีฬานั้น **อนุมัติแล้ว**
- **เฉพาะนักกีฬาในรายชื่อกิจกรรมนี้** เช่น ตั๋วนักกีฬาของนัดฟุตบอล

### เพิ่มลงปฏิทิน

ที่หน้ากิจกรรมกด **เพิ่มลงปฏิทิน** เลือก Google Calendar, Microsoft 365 หรือดาวน์โหลดไฟล์ `.ics`
เพื่อให้ปฏิทินในโทรศัพท์เตือนก่อนเวลา

## ตั๋วของฉัน

หน้า **ตั๋วของฉัน** (`/me/tickets`) แสดงตั๋วทั้งหมดที่คุณรับไว้ เปิดได้จากเมนูบัญชี
หรือปุ่ม “ตั๋วของฉัน” ในหน้ากิจกรรม

- **แสดงตั๋ว** เปิด QR สำหรับเช็คอิน
- **ยกเลิกตั๋ว** คืนที่นั่งให้คนอื่น ยกเลิกได้จนกว่าจะเช็คอิน

<Screenshot
  src="participant/my-tickets"
  mobile="participant/my-tickets-mobile"
  alt="หน้าตั๋วของฉัน"
/>

<Callout title="ยกเลิกแล้วรับใหม่ได้ไหม?">
  ได้ ถ้ากิจกรรมยังเปิดรับและตั๋วยังไม่เต็ม แต่ QR จะเป็นรหัสใหม่ ตั๋วเดิมที่ยกเลิกใช้เช็คอินไม่ได้แล้ว
</Callout>
