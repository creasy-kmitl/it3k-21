<PageHero spot="phone-qr">
  เว็บไซต์ IT3Kings ใช้ **บัญชี Google** ในการเข้าสู่ระบบเท่านั้น ไม่มีการตั้งรหัสผ่านแยก
  หน้านี้อธิบายว่าอีเมลไหนเข้าได้ทันที อีเมลไหนต้องรอคำเชิญ และหลังเข้าสู่ระบบแล้วต้องทำอะไรต่อ
</PageHero>

## เข้าสู่ระบบ

<Steps>
<Step>

### เปิดหน้าแรกแล้วกด “เข้าสู่ระบบ”

ปุ่มอยู่กลางหน้าแรก หรือไปที่หน้า `/login` โดยตรงก็ได้

</Step>
<Step>

### กด “เข้าสู่ระบบด้วย Google”

เลือกบัญชี Google ที่จะใช้ตลอดงาน แนะนำให้ใช้ **อีเมลมหาวิทยาลัย** เพราะระบบสร้างบัญชีให้ทันที

</Step>
<Step>

### ระบบพาไปหน้าถัดไปให้เอง

- ยังไม่เคยกรอกโปรไฟล์ → ไปหน้า **ลงทะเบียนผู้เข้าร่วม**
- กรอกโปรไฟล์แล้ว → ไปหน้า **โปรไฟล์ของฉัน**
- เป็นทีมงาน → ไปหน้า **ระบบทีมงาน**

</Step>
</Steps>

## อีเมลไหนเข้าได้บ้าง

<SignupGate />

| อีเมลที่ใช้                                                                | ผลลัพธ์                                                             |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `@kmitl.ac.th` `@kmutt.ac.th` `@kmutnb.ac.th` (รวมโดเมนย่อยของสถาบันเหล่านี้) | สร้างบัญชีให้ทันที เริ่มต้นเป็น **Guest**                             |
| อีเมลอื่นที่ได้รับคำเชิญ                                                    | สร้างบัญชีตามคำเชิญ (บทบาท ฝ่าย และสถาบันตามที่ผู้เชิญกำหนด)        |
| อีเมลอื่นที่ไม่มีคำเชิญ                                                     | เข้าไม่ได้ ขึ้นข้อความ “อีเมลนี้ต้องได้รับคำเชิญก่อนเข้าใช้งาน”       |

<Callout type="warn" title="ต้องใช้อีเมลเดียวกับในคำเชิญ">
  คำเชิญผูกกับอีเมลที่ระบุไว้เท่านั้น ถ้าได้คำเชิญที่ `name@gmail.com` ต้องเข้าสู่ระบบด้วยบัญชี Google
  ของ `name@gmail.com` ภายใน 14 วัน ถ้าคำเชิญหมดอายุ ให้ติดต่อฝ่าย Tech/Live หรือฝ่ายทะเบียนเพื่อส่งใหม่
</Callout>

<Callout type="info" title="ใช้ Discord เข้าสู่ระบบไม่ได้">
  Discord ใช้สำหรับ **เชื่อม** กับบัญชีเพื่อสมัครกีฬา Esports เท่านั้น ให้เข้าสู่ระบบด้วย Google ก่อน
  แล้วค่อยเชื่อม Discord ที่หน้าสมัครกีฬา
</Callout>

## หลังเข้าสู่ระบบ: บัญชี Guest

บัญชีใหม่ทุกบัญชีเริ่มเป็น **Guest** ซึ่งยังรับตั๋วหรือสมัครกีฬาไม่ได้ หน้าแรกจะแสดงปุ่ม
**ลงทะเบียนเข้าร่วม** ให้กดเพื่อกรอกโปรไฟล์ เมื่อส่งโปรไฟล์แล้ว บัญชีจะเปลี่ยนเป็น **ผู้เข้าร่วม** ทันที

<Screenshot
  src="guest/home"
  mobile="guest/home-mobile"
  alt="หน้าแรกของบัญชี Guest มีปุ่มลงทะเบียนเข้าร่วม"
/>

ถ้าคุณเปิดลิงก์ของระบบทีมงานทั้งที่ยังไม่ได้เป็นทีมงาน ระบบจะพาไปหน้า **รอสิทธิ์เข้าใช้งาน**
ซึ่งเป็นเรื่องปกติ ถ้าคุณควรเป็นสตาฟ ให้แจ้งหัวหน้าฝ่ายของคุณ หรือฝ่าย Tech/Live ให้กำหนดสิทธิ์ให้
