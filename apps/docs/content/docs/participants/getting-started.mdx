## เข้าสู่ระบบ

ระบบใช้บัญชี Google ในการเข้าสู่ระบบเท่านั้น

- ถ้าใช้อีเมลมหาวิทยาลัยของ สจล. มจธ. หรือ มจพ. (`kmitl.ac.th`, `kmutt.ac.th`, `kmutnb.ac.th` รวมถึงโดเมนย่อย)
  ระบบจะสร้างบัญชีให้ทันทีเมื่อเข้าสู่ระบบครั้งแรก
- ถ้าใช้อีเมลอื่น ต้องได้รับ **คำเชิญ** ทางอีเมลจากสตาฟก่อน แล้วเข้าสู่ระบบด้วยอีเมลที่ได้รับคำเชิญ

## กรอกข้อมูลผู้เข้าร่วม

หลังเข้าสู่ระบบ ให้กรอกข้อมูลส่วนตัวและเลือกสถาบันให้ครบ

<Callout type="warn">
  เมื่อส่งข้อมูลแล้ว จะเปลี่ยนสถาบันเองไม่ได้ ถ้าเลือกผิดให้ติดต่อฝ่ายทะเบียน
</Callout>
