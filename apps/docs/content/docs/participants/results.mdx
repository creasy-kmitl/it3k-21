  **โปรแกรมและผล** (`/matches`) **กำลังแข่ง** (`/live`) และ **ตารางคะแนน** (`/standings`)

## โปรแกรมและผล

หน้า `/matches` รวมทุกแมตช์ของทุกกีฬา มีสองมุมมอง

- **รายการ**: แมตช์แบ่งตามวัน พร้อมสถานะ เวลา สนาม และผล กรองได้ด้วย **กีฬา** **ประเภท** **วัน** **สนาม** และ **สถานะ**
  ตัวกรองเก็บไว้ในลิงก์ ส่งลิงก์ให้เพื่อนแล้วเห็นแบบเดียวกัน
- **สายการแข่ง**: รอบน็อกเอาต์เรียงจากรอบแรกทางซ้ายไปนัดชิงทางขวา แยกตามประเภท นัดชิงอันดับ 3 อยู่สายแยกด้านล่าง

<Screenshot src="public/matches-bracket" alt="สายการแข่งในหน้าโปรแกรมและผล" />

ผลในการ์ดแสดงตามแบบของกีฬา เช่น คะแนนแยกตามครึ่งหรือเซต จำนวนเกมที่ชนะ หรืออันดับพร้อมเวลา

| สถานะ          | ความหมาย                                   |
| -------------- | ----------------------------------------- |
| ยังไม่เริ่ม      | ยังไม่ถึงเวลาแข่ง                            |
| เปิดรายงานตัว   | นักกีฬารายงานตัวที่สนามได้แล้ว                  |
| กำลังแข่ง       | แข่งอยู่ คะแนนอัปเดตสด                        |
| จบแล้ว         | มีผลแล้ว                                   |
| เลื่อน / ยกเลิก  | เลื่อนเวลาหรือยกเลิกแมตช์                       |

ฝั่งที่ยังไม่รู้ทีมแสดงเป็นตัวเอียง เช่น *ผู้ชนะ M2* แมตช์ของประเภทที่มีไม่ถึง 3 ทีมมีป้าย **นัดกระชับมิตร** และไม่นับคะแนน

## หน้าแมตช์

กดแมตช์เพื่อดูรายละเอียด

<Screenshot src="public/match" mobile="public/match-mobile" alt="หน้าแมตช์สาธารณะ ผลการแข่งและแท็บรายชื่อ" />

- ทีมที่แข่ง สถานะ ตารางคะแนนแยกตามช่วง เวลา สนาม และกรรมการ
- **ไทม์ไลน์**: ทุกแต้มและเหตุการณ์ตามเวลา พร้อมชื่อและเบอร์เสื้อของผู้ทำแต้ม (ถ้าผู้ใส่คะแนนระบุไว้)
- **รายชื่อ**: ตัวจริง ตัวสำรอง และเจ้าหน้าที่ทีมของแต่ละฝั่ง แสดงชื่อกับเบอร์เสื้อ ไม่มีนามสกุลหรือข้อมูลติดต่อ
- **กติกา**: กติกาของประเภทนั้น
- **รูปภาพ** ที่ทีมงานเพิ่มไว้ (ถ้ามี)

ระหว่างแข่ง หน้านี้อัปเดตคะแนนเองโดยไม่ต้องรีเฟรช

## กำลังแข่ง

หน้า `/live` อัปเดตอัตโนมัติทุก 5 วินาที แสดงแมตช์ที่กำลังแข่งพร้อมคะแนนสด **แมตช์ถัดไป** และ **ผลล่าสุด**
ถ้าไม่มีแมตช์ที่กำลังแข่ง จะขึ้น "ยังไม่มีแมตช์ที่กำลังแข่ง" และยังเห็นแมตช์ถัดไปด้านล่าง

<Screenshot src="public/live" alt="หน้ากำลังแข่ง ตอนยังไม่มีแมตช์ที่แข่งอยู่ พร้อมแมตช์ถัดไป" />

### โหมดจอทีวี

กด **โหมดจอทีวี** (หรือเปิด `/live?tv=1`) เพื่อแสดงผลเต็มจอบนพื้นเข้ม ไม่มีเมนู และหมุนเปลี่ยนแมตช์ทุก 10 วินาที
เหมาะกับจอที่สนามหรือในห้องประชุม ถ้าเน็ตหลุด จอจะบอก "เชื่อมต่อไม่ได้ กำลังลองใหม่…" แล้วกลับมาเองเมื่อเชื่อมต่อได้

## ตารางคะแนน

หน้า `/standings` มีสามส่วน

| ส่วน             | แสดงอะไร                                                                                      |
| ---------------- | -------------------------------------------------------------------------------------------- |
| ตารางเหรียญ       | เหรียญทอง เงิน ทองแดง อันดับ 4 และคะแนนรวมของแต่ละสถาบัน อันดับ 1–4 ได้ 4 / 3 / 2 / 1 คะแนน         |
| ผลรายประเภท       | อันดับสุดท้ายของแต่ละประเภทที่แข่งจบแล้ว                                                         |
| ตารางคะแนนในสาย   | ตารางรอบแบ่งกลุ่มของแต่ละประเภท: แข่ง ชนะ เสมอ แพ้ ได้-เสีย ผลต่าง และแต้ม พร้อมวิธีตัดสินเมื่อแต้มเท่ากัน |

ประเภทที่มีไม่ถึง 3 ทีมเป็นนัดกระชับมิตร ไม่นับเหรียญและคะแนน ตารางคะแนนในสายนับเฉพาะแมตช์ที่จบแล้ว
