  โปรไฟล์ผู้เข้าร่วมคือข้อมูลที่ทีมงานใช้จัดงาน เช่น ชื่อ เบอร์โทร สถาบัน และข้อมูลสุขภาพ
  เมื่อส่งโปรไฟล์ครั้งแรก บัญชีของคุณจะเปลี่ยนจาก **Guest** เป็น **ผู้เข้าร่วม** และรับตั๋วกิจกรรมได้ทันที
</PageHero>

## กรอกโปรไฟล์ครั้งแรก

เปิดหน้า **ลงทะเบียนผู้เข้าร่วม** (`/signup`) จากปุ่ม “ลงทะเบียนเข้าร่วม” ที่หน้าแรก
ระบบ **บันทึกร่างให้อัตโนมัติ** ทุกครั้งที่พิมพ์ จึงปิดหน้าแล้วกลับมากรอกต่อได้

<Screenshot
  src="guest/signup"
  mobile="guest/signup-mobile"
  alt="แบบฟอร์มลงทะเบียนผู้เข้าร่วม"

/>

<Steps>
<Step>

### เลือก “รูปที่มั่นใจที่สุด” (จำเป็น)

ต้องเห็นใบหน้าชัดเจน ไม่สวมแมสก์ ไม่สวมแว่นตา ใช้ไฟล์ JPEG, PNG หรือ WebP ขนาดไม่เกิน 10 MB
รูปนี้ใช้ยืนยันตัวตนที่หน้างาน

</Step>
<Step>

### กรอก “ข้อมูลส่วนตัว”

คำนำหน้า (นาย / นาง / นางสาว) ชื่อ นามสกุล ชื่อเล่น เบอร์โทรศัพท์ และมหาวิทยาลัย/สถาบัน
เบอร์โทรใช้รูปแบบ `0XXXXXXXXX` (10 หลัก) หรือ `+66…` ก็ได้

ถ้าเข้าสู่ระบบด้วยอีเมลสถาบัน ระบบจะเลือกสถาบันให้ล่วงหน้า ตรวจให้ถูกก่อนส่ง

</Step>
<Step>

### กรอก “สุขภาพและอาหาร” (ไม่บังคับ)

โรคประจำตัว ประวัติการแพ้ยา อาหารที่แพ้ และข้อจำกัดด้านอาหาร
ข้อมูลส่วนนี้ช่วยให้ฝ่ายพยาบาลและฝ่ายสวัสดิการดูแลคุณได้ถูกต้อง

</Step>
<Step>

### กด “ยืนยันลงทะเบียนผู้เข้าร่วม”

ระบบส่งอีเมล “ได้รับข้อมูลลงทะเบียนของคุณแล้ว” และพาไปหน้า **โปรไฟล์ของฉัน**

</Step>
</Steps>

<Callout type="warn" title="เลือกสถาบันให้ถูกตั้งแต่ครั้งแรก">
  เมื่อส่งโปรไฟล์แล้ว **เปลี่ยนสถาบันเองไม่ได้** (ช่องจะขึ้นว่า “เปลี่ยนสถาบันเองไม่ได้แล้ว”)
  สถาบันมีผลกับการสมัครกีฬาและสิทธิ์รับตั๋วบางประเภท ถ้าเลือกผิดให้ติดต่อฝ่ายทะเบียน
</Callout>

### สถานะร่างที่เห็นด้านบนแบบฟอร์ม

| ข้อความ                     | ความหมาย                                                 |
| --------------------------- | -------------------------------------------------------- |
| บันทึกร่างแล้ว              | ข้อมูลล่าสุดถูกเก็บแล้ว                                   |
| มีข้อมูลรอบันทึก / กำลังบันทึกร่าง… | กำลังส่งข้อมูลที่เพิ่งพิมพ์                          |
| บันทึกร่างไม่สำเร็จ          | เน็ตหลุดหรือระบบมีปัญหา ลองอีกครั้งก่อนปิดหน้า             |
| ข้อมูลเปลี่ยนแปลงจากหน้าอื่น | คุณเปิดแบบฟอร์มไว้หลายแท็บ ให้ใช้แท็บล่าสุด               |

## หน้าโปรไฟล์ของฉัน

หน้า **โปรไฟล์ของฉัน** (`/me`) รวมทุกอย่างของคุณไว้ในที่เดียว

- รูป ชื่อ บทบาท และสถาบัน
- **รหัสผู้ใช้** พร้อมบาร์โค้ด ใช้เช็คอินแทนตั๋วได้ในบางจุด (ดู [การเช็คอิน](/docs/participants/check-in))
- ข้อมูลการลงทะเบียนทั้งหมด
- การ์ด **ตั๋วกิจกรรม** และ **การสมัครกีฬา** (สำหรับนักกีฬา)

## แก้ไขโปรไฟล์

กด **แก้ไขข้อมูล** มุมขวาบนของหน้าโปรไฟล์ แบบฟอร์มเดิมจะเปิดขึ้นพร้อมข้อมูลที่เคยกรอก
แก้แล้วกด **บันทึกข้อมูลโปรไฟล์** แก้ได้ทุกช่อง ยกเว้นสถาบัน

<Screenshot src="participant/profile-edit" alt="แบบฟอร์มแก้ไขโปรไฟล์" />

## เมนูบัญชี

กดรูปหรือชื่อของคุณที่มุมขวาบน เพื่อเปิดเมนูไปหน้าโปรไฟล์ ตั๋วของฉัน กิจกรรม หรือออกจากระบบ
ถ้าคุณเป็นนักกีฬาจะมีเมนู **ระบบนักกีฬา** และถ้าเป็นทีมงานจะมีเมนู **ระบบทีมงาน** เพิ่มขึ้นมา
